- 宿主采用有界的控件遍历与正文可达检查，无法证明任意复杂应用的所有交互路径正确；未通过的候选不会启用。引用与精确阅读位置继续使用可信原文阅读器，设计页不能伪造正文引用。
- 设计页当前使用安全正文文本投影；作者 Markdown 原文可通过可信原文阅读器查看。未提供跨任务模板库、用户代码编辑器或全局 App UI 改写。
- 旧作者展示没有兼容、恢复或转发入口。测试中的旧字段仅用于证明退役和正文保留。

这些是实际能力和覆盖范围，不是用户批准免除产品约束；在线质量仍应作为后续实际试用的验证项。

## 2026-11-06 长文滚动修正

用户实测发现任务详情与正文各有一个纵向滚动区域。原文的限高、`overflow:auto` 和 `overscroll-behavior:contain` 在真实 Electron 长文场景中复现了问题，修复前回归明确失败于“正文不应在任务详情内再建立纵向滚动框”。

修正后正文使用所在任务或联系人详情的主滚动容器，缓存规范正文与哈希，按正文相对位置保存和恢复进度。任务标签分别记住其真实容器位置。成果标签的操作栏置于滚动区域上方，成果集返回栏跟随标题栏实际高度，避免窄窗换行时遮挡。隔离展示按正文高度展开，校验来源后接收尺寸和翻页消息；动态后代制造纵向滚动、视口高度反馈循环时回退原文，正常有限动画与宽度变化不作为反馈循环。

验证记录：全量 2352 项通过、62 项跳过；最终针对性 14 项通过；Node/Web 类型检查、模块边界与构建通过。真实 Electron 设计师专项和成果集专项通过，覆盖滚轮输入、PageDown/Home、标签往返、关闭前保存、重启后继续阅读、原版本不被后台更新替换、375/1024 宽及深浅色、动态内层滚动回退、100vh 高度循环回退和正常短动画。独立审查发现的实际滚动容器与尺寸保护问题已修复并复审。
