# 日志本地语义索引

2026-09-09 已接入持久来源向量复用。准备检索时读取当前来源、校验服务配置和本地索引，展示可复用的去重文字数量与本次实际发送的文字、字符及批次数。只有明确确认后才发送缺失的文字。普通查询不单独写入持久索引；如果查询文字恰好与已索引来源块完全相同，也可复用该向量。

索引位于日志 SQLite 数据库，与来源记录使用同一套删除事务和触发器。只保存来源 ID、内容摘要、块摘要和数值向量，不复制标题、OCR 正文或查询原文。连接范围由 Embedding 地址、模型、供应商、启用状态和凭据的 SHA-256 摘要区分，不在索引表保存明文凭据。地址、模型或密钥变化不会使用原范围索引；旧范围条目可清空或按容量淘汰。

来源应用名、标题或 OCR 更新时删除对应索引；删除活动或画面时同步删除其所有连接范围索引，包括保留期清理。写入前再次核对数据库中的来源内容，防止删除后复活。查询范围改变而来源文字未变时仍可复用向量；排序使用本次读取的日期和来源对象。

索引最多 4096 条来源、64 MiB 序列化数据，单条来源最多 8 MiB；超过总容量按最近使用时间淘汰。此数字是索引值的数据预算，不代表 SQLite/WAL 文件一定立即缩小。完整检索仍遵守最多 31 天、600 条来源、200 万源字符和 512 个文本块限制，不通过缓存扩大覆盖范围。

「清空本地语义索引」只删除向量记录，不删除日志来源。清空同时取消当前检索并递增数据库索引代次，之前的请求不能在清空后重新写回。损坏索引被移除，后续预览会将相应文字计入重新发送范围。若检索结果有效但索引写入因容量或磁盘原因失败，保留检索结果并明确提示索引未保留，不自动重试网络请求。

验证：447 项单测、类型检查、构建与完整 Electron 回归通过（`temp/journal-semantic-cache-smoke.log`）。单测覆盖跨检索实例复用、只发送新查询、内容/凭据变化、清空时取消晚到响应及写入失败反馈。真实 SQLite 覆盖重开持久化、范围隔离、OCR/来源删除清理、清空代次保护、损坏恢复和 4096 条容量淘汰。界面与本地 HTTP 服务验证首次预览零请求、确认检索、再次查找只发送查询、取消、清空后重新预览不复用也不联网。

测试向量为人工构造，持久化复用不代表已验证真实模型召回质量。若服务端在不更改模型标识的情况下更换模型，可能需要手动清空索引重新建立；真实模型召回及无答案评测仍待完成，见 [评测说明](journal-retrieval-evaluation.md)。
