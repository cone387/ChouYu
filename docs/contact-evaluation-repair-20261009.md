# 联系人评审格式修复验收（2026-10-09）

涉及 RUN-02、MSG-03、HIST-01；不改 UI、权限、额度、失败退避或自动恢复规则。

## 真实记录

只读检查本机阿衡的任务「阿想·Idea实验员产品评价持续实验」。最近三轮均失败，联系人 failures=3，自动推进已阻塞。第三轮已读取阿想 toC #28–30 的真实成果，初次与修复输出均因顶层 nextStep 缺失/空值被拒绝；此前两次分别为无法解析完整 JSON，修复后仍缺标题或成果完成条件/摘要。旧原始模型输出未完整留存，不能断言第三轮当时的 progress.nextStep 有效，也不能声称三次失败均由同一缺陷造成。

## 实现

- 有 progress 时先严格校验它，再从 progress.nextStep 派生报告 nextStep，删除对重复字段的独立强制要求；即使顶层冲突也使用原本运行期就采用的进展下一步。
- 不从 evaluations 的产品验证建议或历史计划猜补；缺进展下一步、原因或判断仍拒绝。已结束任务允许明确的空下一步；无 progress 的旧报告仍要求原字段。
- 生成提示明确唯一来源；有成果版本的格式修复携带完整 delivery 协议，不只告诉模型保留 delivery。仍一次修复、计入额度、严格校验评分与证据、保存成功才投递。
- 未修改生产数据库或清空失败次数。代码更新不等于真实任务恢复；加载新代码后仍需对失败任务重试，观察实际模型输出与成果落盘。
