# 联系人活动与消耗

联系人顶部「消耗」入口查看全部任务；任务的悬浮「消耗」按钮查看当前任务。支持单日、截至所选日期的近 7 天与近 30 天。单日按小时、跨日按当地自然日汇总，点击跨日图表进入当天。切换到工作记录后可返回看板，保留筛选。

日时间轴展示每个任务的执行、排队、等待回复、中断，以及报告和失败标记。空白表示没有已记录的执行轮次，不据此推断是否关机或任务被暂停。Token 图可切换分时输入/输出/未分项堆叠柱状图和累计折线；执行时间使用独立图表。图表可用键盘选择，并提供表格数值。

## 统计口径

- 仅统计联系人任务工作，不包含普通聊天。读取所有保留轮次，不受概览最近 30 轮限制；删除任务同时删除其统计来源。
- 调用次数按请求发起时间，用量按模型响应结束时间归属；失败和重试计入。跨日请求因此可能在不同日期体现调用次数和 Token。
- 用量完整度的分母是归属本时段的用量记录数，不是本时段发起调用数。缺少用量不估算、不当成零；图上的 `?` 提示缺失。缓存等额外用量可能导致输入加输出小于总数。
- 执行耗时按阶段事件计算，排队、等待回复、中断单列，跨日/小时按实际重叠区间拆分。任务概览原有「累计耗时」是轮次起止总时长，两者含义不同。
- 旧调用没有结束时间时按发起时间归属；旧运行阶段根据已有工作事件推算。历史停机时段无法精确还原，不把空白自动标记为等待。
- 报告数指已保存的工作报告，不等于新增 Idea 或成果分节数量。
- 所有日期以应用本地时区计算。当天未来时段留空；看板可见时每 10 秒及工作事件更新时刷新。

新增数据兼容现有 SQLite 数据版本：模型调用 metadata 增加 recordedAt；运行状态切换为 running 时写 execution-start 事件。不修改模型预算或调度策略。
