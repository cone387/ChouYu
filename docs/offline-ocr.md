# 离线文字识别

在聊天输入区添加图片，点击“离线识别首张”。此入口手动运行 Windows 系统 OCR；不需要 AI 配置，也不会调用 AI Provider。图片在本机临时目录中处理，完成或失败后尝试删除本次临时文件和空目录。

有文字时，结果追加到现有草稿，并移除处理过的图片；其他附件保留。用户检查、编辑后再决定是否发送。没有文字或失败时保留图片，显示提示，不自动切换为联网识别。运行中删除/发送该图片、切换会话或关闭面板后，不把晚到的结果插入其他草稿。

当前仅支持 Windows 和 PNG/JPEG/WebP/BMP，输入约 16 MB 上限、20 百万像素上限，还受 Windows OCR 最大边长限制。使用当前系统语言对应的已安装 OCR 语言包；缺少语言包、系统策略阻止启动、尺寸过大或 30 秒超时都会提示失败。未安装语言包时需在 Windows 语言设置中安装相应识别支持。多语言混排、手写与复杂版式的识别准确率仍需专项评测。

识别进程使用固定 PowerShell 脚本、不加载用户 Profile、不打开窗口；仅传递临时图片路径和最小环境变量，不向子进程继承应用 API Key。未降低系统脚本执行策略。进程隔离不等同于操作系统安全沙箱；异常强制终止应用可能留下临时文件。

## 验证

- `npm test` 覆盖非法输入、进程参数/环境边界、语言包失败、并发拒绝、超时、清理与重试。
- 配备 Windows OCR 语言包的机器运行 `npm run test:smoke:ocr`，真实拖入 `tests/fixtures/ocr-sample.png`、点击入口，验证识别内容、草稿保留、图片移除和没有新增 Provider 请求。
- 2026-09-07 本机 `zh-Hans-CN` 引擎识别出测试图全部英文文本，真实 UI 冒烟通过，已复核亮暗主题及窄视口。此结果不是对所有图像准确率的承诺。
- `1.3.0-rc.2` 包内 OCR 识别与移除图片后的晚到结果处理已通过；中文文件路径的独立 helper 验证也已通过。`rc.1` 不包含离线 OCR。

参考：[Microsoft OcrEngine](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine?view=winrt-26100)。
