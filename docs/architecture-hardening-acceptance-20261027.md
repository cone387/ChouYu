# 架构加固验收（2026-10-27）

用户要求先修复架构审查的五项问题，再推进持续探索功能。实现分支 `fix/architecture-hardening`；源码版本仍为 1.4.2，本记录不表示发布了新安装包。

## 范围与不变约束

保留模块化单体、共享 WorkLoop 进程、任务域、原生/DSH 执行器和共同任务界面。单描述任务表单、保存正文直接交付、来源、权限、预算与主动未读闪烁沿用现行 [联系人任务规范](contact-task-spec.md)。不新增持续探索功能，也不使用真实用户资料或在线模型验证这些基础修复。

## 修复与回归

### DSH 取消与运行池

真实本地 TCP/Node 故障 helper 覆盖连接仍存活但 run 不返回、cancel 无回应或已回应但运行未结束。默认 15 秒取消宽限只从明确取消开始，不给人工确认等待加总时限。异常运行组必须结束实际执行和宿主工具后才释放容量；同组受影响请求失败，不自动重放。正常单任务取消保持隔离。

独立审查追加发现并修复 `round:before` 等待预算预留时未被排空的问题。现在完整跟踪宿主回调（包括上下文复核、预算预留和工具执行），关闭后拒绝新回调，异步返回后再次检查取消状态，等待回调结束后才最终结算预算。两项原始回归先失败再通过，补齐自身/同组故障的四种上下文与预留场景及迟到工具检查；DSH 定向 9 文件 67 项通过，修复后再次独立复核无新增阻塞。

运行池通过租约保护活跃组，默认最多 8 个配置组、空闲 5 分钟回收。覆盖启动失败、取消获取、重复释放、提前释放、并发获取和关闭；仅清除 Map 不算进程回收。Windows 真实 helper 和孙进程回归确认进程树结束；终止失败时保留占位并重试，不能将终止命令已发出当作实际退出。

### 退出屏障

`CompanionBriefing.close()` 停止接收检查、取消在途检查并等待实际操作结束；排队请求不再启动，关闭期间不推进基线或投递消息，已持久待发送正文保留给下次启动。定时安排的关闭等待本轮生成退出；自然语言任务解析和交接准备纳入取消与等待。

主退出入口在最终 flush 前停止待办调度、稍后提醒和剪贴板监听，并等待助手检查/解析、聊天/联系人执行、日志关闭。同步移除 `proactive:append` 入口，防止隐藏窗口继续发来休息提醒。任务域存储保留至在途工具结束后关闭。保存失败继续沿原专用恢复对话框重试，`db:retry-save` 通道保留。

先添加失败测试，再验证：companion 检查/生成/恢复复核三个场景、routine 生成 drain、模块入口关闭检查与任务解析、待办停止调度但域仍可读。专项 5 文件 62 项通过。独立审查发现并修复了休息提醒 IPC 的迟到入口；真实 IPC → 投递 → SQLite 回归在挂起备份期间验证最终 flush 后不新增消息或回执，保存重试仍可用。最终验证统一见下方。

### 独立消费账本

联系人库 schema 20 → 21，新增按联系人拥有的 `daily_consumption`。模型与搜索的历史记录和消费记录同事务写入；任务/轮次删除不删除消费。角色本身删除继续清除其数据，与原 Token 账本行为一致。

旧库在初始化事务内从仍存在的调用历史迁移，重复打开不重复计数，失败回滚。旧版本已经删除的消费没有证据，不能从 Token 估算补造。Token 准入拒绝、尚未请求供应商的调用通过专用原子接口撤销；已预留 Token 或已记录响应的调用不能撤销。恢复额度基线也读取独立账本。

首批 6 项回归中 5 项按预期失败；实现后专用 10 项通过，相关回归两组分别为 54、53 项通过。涵盖删除后重开、上限阻止、跨日、旧库迁移重复/失败、恢复授权和未发出请求释放。

### 消息增量保存

正常主动投递只插入新消息，消息、回执、会话投影同事务保存；已加载正文缓存增量更新，冷会话不为写入加载正文。已读水位独立更新，不重写消息正文。普通编辑、附件及先前保存失败沿原脏数据恢复机制；投递前先提交待保存编辑，不能因其他会话编辑而重写目标会话历史。

1,000/10,000 条历史使用真实 SQL trigger 和生产 database 接口验证，不以仅未更新行数替代“没有遍历所有历史执行 upsert”。ID 冲突拒绝覆盖，回执失败整体回滚，清空后旧回执仍阻止重发，旧编辑不篡改正式交付正文。

独立审查完成 655 次实际仓储增量投影与原 `projectConversation` 对照，包含乱序/同时间戳、空正文、回复完成和已读边界，结果一致；独立运行存储与投递相关 4 文件 106 项通过。

## 保留边界

- 活动聊天仍按既有 API 返回完整正文；普通编辑和之前未提交的修改可能需要全会话保存。
- 已读更新不写正文，但仍需 SQL 查找时间戳与剩余未读候选；全文搜索、备份校验/fsync 和历史渲染不是本轮全面改造范围。
- 共享进程或 DSH 配置组故障会影响同组工作，必须明确失败；本轮不声称每联系人进程隔离。
- 故障注入和有限增长回归不等于真实断电、全天常驻、任意 Provider 或新安装包验收。
