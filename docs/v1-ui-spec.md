# V1 UI 规格

## 整体交互流程

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  [常态] 角色在桌面上，idle 动画                                   │
│         ↓                                                       │
│  [唤出] 点击角色 / Alt+Space → 聊天面板弹出（跟随角色位置）       │
│         ↓                                                       │
│  [对话] 在面板中输入 → 发送 → 流式回复                           │
│         ↓                                                       │
│  [收起] Esc / 点击面板外 → 面板关闭 → 回到常态                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

核心原则：全局只有一个聊天面板，点击角色 = Alt+Space = 打开/关闭面板
```

---

## 界面元素

系统中只有 2 个 UI 元素：

| 元素 | 类型 | 常驻 | 尺寸 |
|------|------|------|------|
| 角色 | 透明窗口内的 SVG | 是 | 80×80px |
| 聊天面板 | 同窗口内的浮动面板 | 否（点击/快捷键切换） | 宽 400px，高 520px |

## 1. 角色

```
┌─────────────────────┐
│                     │  ← 透明区域（点击穿透）
│    ┌───────────┐    │
│    │           │    │
│    │  (°▽°)   │    │  ← 80×80 角色区域（可交互）
│    │           │    │
│    └───────────┘    │
│                     │
└─────────────────────┘

窗口实际大小: 120×120（留 padding 给动画溢出）
角色渲染区: 80×80 居中
```

**行为：**
- 左键按住角色 → 拖拽移动
- 左键单击角色 → 打开/关闭聊天面板
- 右键角色 → 上下文菜单（设置/退出）
- 拖到屏幕边缘 20px 内自动吸附
- 位置持久化（退出保存，启动恢复）

**动画状态：**
```
idle:     translateY 上下浮动 3px，周期 2s + 每 4s 眨眼
thinking: 缩放 pulse 0.95~1.05，周期 0.8s
talking:  轻微弹跳 translateY -2px，周期 0.3s
sleeping: scale(0.9) + opacity(0.7) + ZZZ 粒子
happy:    scale 1.0→1.2→1.0 弹跳一次（0.4s）
```

- 无消息时（紧凑模式）：只显示顶栏 + 输入区域，约 160px

### 2.3 输入区域（统一容器风格）

输入区域是一个整体圆角容器，工具栏嵌入在输入框内部底部（类似 ChatGPT/Claude 的输入框样式）。

```
┌──────────────────────────────────────────┐
│ 输入消息，/ 打开指令菜单...               │  ← placeholder
│                                          │
│                                          │  ← 多行文本区域
│                                          │
│  [📎附件]              [模型▾]    [⏎]   │  ← 内嵌工具栏
└──────────────────────────────────────────┘

整体容器: 统一圆角边框，视觉上是一个输入框
文本区域: 上部，最小 2 行，最大 ~6 行，超出滚动
工具栏:   容器内部底部，与文本区域无分隔线
```

**输入框行为：**
- Enter 发送，Shift+Enter 换行
- 输入 `/` 时弹出指令菜单
- 支持粘贴图片（显示为缩略图附件）
- 支持拖入文件（显示为文件附件标签）

**内嵌工具栏：**

| 元素 | 说明 |
|------|------|
| [📎] | 附件按钮：点击选择文件（V1 预留，可不实现） |
| [模型▾] | 当前使用的模型，点击切换（如 gpt-4o / claude-sonnet） |
| [⏎] | 发送按钮（鼠标可点击，也可 Enter） |

**视觉规格：**
- 容器圆角: 12px
- 容器边框: 1px solid var(--input-border)，获得焦点时边框变为 var(--accent)
- 文本区域: 无边框，背景透明
- 工具栏: 与文本区域同容器，padding 8px 12px，无上边框分隔

### 2.4 / 指令系统

输入 `/` 后弹出指令菜单（V1 搭建框架，预留扩展）：

```
┌──────────────────────────────────────────┐
│ /                                        │  ← 输入框
├──────────────────────────────────────────┤
│                                          │
│  ┌────────────────────────────────────┐  │
│  │  /clear        清空对话，新话题     │  │  ← 指令菜单
│  │  /settings     打开设置             │  │
│  │  /model        切换模型             │  │
│  │  /help         查看可用指令         │  │
│  └────────────────────────────────────┘  │
│                                          │
└──────────────────────────────────────────┘
```

**V1 内置指令：**

| 指令 | 说明 |
|------|------|
| `/clear` | 清空当前对话历史，开始新话题 |
| `/settings` | 打开设置面板 |
| `/model` | 快速切换模型 |
| `/help` | 显示所有可用指令 |

**指令菜单行为：**
- 输入 `/` 后立即弹出
- 继续输入可过滤（如 `/cl` 只显示 `/clear`）
- 上下键选择，Enter 确认
- Esc 关闭菜单
- 选中指令后：
  - 无参数指令（/clear）：直接执行
  - 有参数指令（/model gpt-4o）：填入输入框，用户继续补充

**扩展机制（V2+ 指令示例）：**
```
/translate [文本]    翻译文本
/summarize [文本]    总结内容
/code [描述]         生成代码
/explain [代码]      解释代码
```

## 4. 位置智能计算

面板跟随角色位置，出现在角色对侧：

```
              屏幕
┌─────────────────────────────────┐
│                                 │
│  角色在左侧                      │
│  ┌───┐  ┌──────────────┐       │
│  │Pet│→ │   聊天面板    │       │  → 面板在角色右侧
│  └───┘  │              │       │
│         └──────────────┘       │
│                                 │
│       ┌──────────────┐  ┌───┐  │
│       │   聊天面板    │ ←│Pet│  │  → 角色在右侧
│       │              │  └───┘  │    面板在角色左侧
│       └──────────────┘         │
│                                 │
│  ┌───┐                          │  → 角色在左下角
│  │Pet│                          │    面板在角色右上方
│  └─┬─┘                          │
│    └→ ┌──────────────┐          │
│       │   聊天面板    │          │
│       └──────────────┘          │
└─────────────────────────────────┘
```

**定位算法：**
```typescript
function getPanelPosition(petBounds, panelSize, screenSize) {
  const GAP = 12

  // 水平方向：角色在右半屏 → 面板在左；否则在右
  const isRight = petBounds.x + petBounds.width / 2 > screenSize.width / 2
  const x = isRight
    ? petBounds.x - panelSize.width - GAP
    : petBounds.x + petBounds.width + GAP

  // 垂直方向：面板顶部与角色顶部对齐，向下展开
  let y = petBounds.y

  // 边界修正
  if (x < 0) x = GAP
  if (x + panelSize.width > screenSize.width) x = screenSize.width - panelSize.width - GAP
  if (y + panelSize.height > screenSize.height) y = screenSize.height - panelSize.height - GAP
  if (y < 0) y = GAP

  return { x, y }
}
```

## 5. 动画与过渡

| 场景 | 动画 | 时长 |
|------|------|------|
| 面板打开 | scale(0.95→1) + opacity(0→1) 从角色方向展开 | 200ms ease-out |
| 面板关闭 | scale(1→0.95) + opacity(1→0) 收向角色方向 | 150ms ease-in |
| 指令菜单弹出 | translateY(4→0) + opacity(0→1) | 120ms ease-out |
| 指令菜单关闭 | opacity(1→0) | 80ms |
| 消息出现 | translateY(8→0) + opacity(0→1) | 200ms ease-out |
| 角色状态切换 | crossfade | 300ms |
| AI 正在输入 | 光标闪烁 blink 动画 | 持续 |

**表情状态（通过 JS 切换 SVG 路径）：**
- idle: 默认微笑，每 4s 眨眼

- talking: 嘴巴在 `○` 和 `─` 之间交替（0.3s）
- sleeping: 眼睛变 `− −`，嘴巴变小，+ ZZZ 文字
- happy: 眼睛变 `＾＾`，嘴巴变大弧

## 10. 响应式细节

**面板尺寸约束：**
- 最小宽度: 360px
- 最大宽度: 480px
- 最小高度: 400px
- 最大高度: 屏幕高度 - 100px
- 可通过拖拽面板边缘调整大小（可选，V1 可固定）

**小屏幕适配（< 1366px）：**
- 面板宽度自动缩小到 360px
- 如果角色旁边放不下面板，面板出现在角色正上方

**多显示器：**
- 角色和面板始终在同一个显示器上
- 拖拽角色跨显示器时，面板跟随
