# 全局导航工作区

2026-09-08，工作区源码版本。

左侧固定 56px 纯图标导航，依次为会话、活动、记忆，设置固定在底部。图标提供悬停名称、可访问名称、当前页高亮和方向键/Home/End 焦点导航；Enter/空格进入页面。

外壳采用微信式连续轮廓：左栏与 32px 全局顶栏共用底色，右侧内容以 12px 左上圆角内收，形成“厂”形衔接，不再绘制全局导航右侧的竖线或选中项左侧彩色竖条。顶栏右侧统一放置隐藏、关闭按钮，空白处可拖动窗口；会话列表与聊天内容之间仍保留分隔线。亮暗主题共用语义配色，输入区上浮菜单不被圆角裁切。

页面内不再重复显示“记忆 / 活动 / 设置”标题栏；记忆中心的泛介绍也移除，添加记忆放在列表统计操作行。保留活动记录状态、具体设置分类标题、聊天在线状态及搜索等上下文操作。键盘焦点轮廓与图标悬停提示继续保留。

| 页面 | 布局 |
| --- | --- |
| 会话 | 会话列表与聊天内容，列表可收起 |
| 活动 | 工作日志，包含日期、搜索、事项、画面、总结及按日问答 |
| 记忆 | 记忆库、总览、待处理、整理、连接，按可用能力展示 |
| 设置 | 模型、操作权限、能力、人格、通用、插件和关于 |

切换页面时保持工作区外框宽高，侧栏空间交给当前页面使用。右边缘和上下边缘分别调整宽度、高度；已有尺寸与会话列表显示偏好继续使用。工作区小于 700px 时，会话列表默认收起，手动打开后成为局部抽屉，选择会话或点击遮罩后收起。记忆分区及设置分类在小窗内换行。

页面首次访问后保留挂载：模块切换保留聊天草稿、附件、阅读位置、记忆筛选以及活动日期、搜索和问答；聊天生成继续进行。隐藏活动页停止 UI 轮询，返回时刷新，后台采集服务独立运行。隐藏聊天页不响应截图快捷键。关闭整个面板仍沿用原有卸载行为，以上状态保留针对导航切换与隐藏面板。

聊天顶栏只保留会话内操作与在线状态，窗口控制统一交给全局顶栏。设置分类不再重复排列活动与记忆，但设置搜索仍可以跳转到相应工作区。托盘“工作日志”、`/journal` 和日志 IPC 入口进入同一个主工作区；活动采集进程与数据库不受页面切换影响。
