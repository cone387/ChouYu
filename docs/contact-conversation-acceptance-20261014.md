## 设置与实际执行入口

| 设置域 | 对话/卡片入口 | 手动入口与实际消费者 |
| --- | --- | --- |
| 名称、头像、分类、人设、供应商/模型 | `edit_contact_profile` | 原联系人资料，`updateContactProfile`；普通聊天/后台/主动生成解析有效联系人配置，内置模型使用全局默认归属 |
| 全部工作、资源、通知、网页/搜索、工具策略、共享设置 | `edit_contact_work_settings` | 原工作设置，`AgentStore`保存；原调度/权限/额度/消息服务读取，不写成假文本约束 |
| 搜索凭据 | 安全输入卡片，`set_contact_search_credential` | 原工作设置密钥行；只持久到原凭据配置，不进入模型、聊天、卡片或日志 |
| 技能说明/脚本、安装与环境 | `configure_contact_skill`、真实目录、安装/环境准备工具 | 原技能库/运行器；启用说明不授权脚本，下载成功不代表依赖已就绪 |
| 任务、助手职责/晨报、记忆 | 原任务/助手/记忆注册工具，确认改用持久卡片 | 原公共单描述任务弹窗与各领域服务；继续遵守归属、版本、权限和原执行引擎 |
| 输出偏好 | `set_contact_output_preference` | 原工作设置/成果阅读器的阅读偏好弹窗；公共渲染和原后台、晨报、工作检查生成请求读取 |

同域多字段仍一次校验保存。跨域组合为同一次请求下分开的持久设置卡片，保留分组及步骤序号；分别确认和记录回执，未完成项仍可从原卡片处理，拒绝一项不执行其他项。不是跨域原子事务，也不支持批量任务。卡片创建失败逐项说明，不能宣布组合全部完成。

## 动态输出与审查补正

- 成果分节可保存经过校验的类型/间距描述；无效或未知描述回退完整正文。聊天和阅读器共用 `ContactOutput`，长文默认完整展开，保留表格/引用/阅读器目录、自定义sandbox与固定版本来源。
- 联系人及任务表达要求进入后续原生成请求；仅此版本的排版不改正文。单次表达结构需要重写正文时，绑定实际成果版本提交原修订流程，不能把无消费者的表达要求保存为“已生效”。
- 成果认可只记录对该版的反馈，不结束持续任务、不恢复暂停任务。修订复用原额度/版本/排队事务；旧版或任务变化拒绝。
- 原失败卡可直接展开工作权限、技能库、模型选择及被关闭的工具；保留外部/系统设置入口。保存配置只表示配置保存，原失败须重新尝试才能证明恢复。
- 执行开始先持久化。真实执行后回执写入失败，尽力记录为结果不确定且禁止重放；若存储仍不可用，保留执行标记供启动恢复。用户核对后可明确关闭，不伪造成功回执。非凭据回复保留，凭据不持久化。
- ChouYu晨报和待处理入口保留无任务事项的安全描述与原链接；自然语言提交重新读取事项并派生真实联系人归属。同名卡片支持最新消息中唯一的具体修改内容或原事项链接，含糊同意仍不执行。
- 审查回归：手动密钥读取版本后，另一入口更新密钥，旧保存必须拒绝；输入保留，可显式重新读取再保存。
