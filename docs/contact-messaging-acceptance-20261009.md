# 联系人直接交付验收（2026-10-09）

依据：用户明确要求联系人按独立的人交流，小说应直接交正文，不能把阶段 ID、active/done 和内部进度当作汇报。现行规则已更新至 contact-task-spec.md 第 7 节及 AGENTS.md。

## 实现

- 新成果通知取本轮交付的分节标题与完整正文，不再取 judgement / nextStep，不再附带进度卡片数据。复用现有普通聊天 Markdown，无新增 UI 组件或配置。
- 正文与成果在同一事务内保存；后来修订不会改变此前待送达的消息。相同正文的内部状态变更不重复交付，只有需求/展示元数据更新不伪装新正文。
- 创作、研究、回复后的修订、非必要追问纠正与分段正文恢复均增加自然交流约定；正文不包含执行字段，但技术任务中的合法代码与术语不能被全局替换。
- 评审正文先给结论与实际计算的总分，再展示维度、依据、风险及建议；模型原报总分仍保存在报告结构中，不混入聊天正文。
- 既有失败、必要追问、额度通知、任务定位、可靠投递及未读规则保留。历史消息不改写、不重发。
