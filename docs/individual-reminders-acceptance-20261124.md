# 逐项通知与已读标识验收（2026-11-24）

用户确认「每项各发一条」，不要求等前一条已读。现行产品要求已同步联系人任务规范第 7、10、11 节，以及主动提醒和待办提醒说明。

## 实现

- 持续催办不按会话合并，每项使用自己的到期时间生成稳定回执；逐项检查来源版本、逐项发送和重试。离线错过多期仍只补当前一次。
- 待办启动积压和休眠恢复共用普通单项投递，任务/子项来源与回执独立。已有合并消息保留，不重新拆发。调度器原生恢复事件仍可携带总数，不再由此生成合并聊天正文。
- 聊天阅读标识来自当前消息的持久阅读回执与会话阅读边界，不能使用原事项「曾经读过」来标记新催办。通知刷新合并阅读事实，不回退已读、不覆盖本地流式正文。
- 已读、待处理、已处理和已失效独立展示；处理后仍显示阅读状态。手动标读沿用原单事项语义，标记该事项现有的关联消息，不影响其他事项。阅读不结束持续提醒，未读闪烁保持。
