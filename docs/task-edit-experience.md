# 任务编辑体验

本文适用于用户待办模块，不适用于联系人任务。联系人新建、设置与编辑遵循 [联系人任务 spec](contact-task-spec.md) 的单描述弹窗规范。

## 公共日期时间弹窗（2026-10-09）

- 日历核心使用 React DayPicker 9.14.0，公共组件为 `components/common/DateTimePicker.tsx`，样式独立于任务表单。统一使用应用颜色、边框与字体变量，支持浅色、深色和窄窗口。
- 开始/截止时间、子项截止时间、自定义提醒、重复结束日期、任务卡片截止时间全部复用同一弹窗；支持 `date`/`datetime` 模式、最小/最大日期、禁用和清除控制。业务层继续负责提醒平移、重复规则和存储。
- 本地日期字符串按本地时间解析，严格拒绝 2 月 31 日等无效日期；日期和时间紧凑地并列显示在日历下方。点击时间在日历原区域切换到时分选择，弹窗、摘要行和确认按钮位置不变；可返回日历，保留已选日期、月份和时间。小时、分钟两列各显示五项，提供 00、15、30、45 常用分钟直选，仍可选择任意分钟。使用 24 小时格式，支持键盘上下方向键和 Home/End，不要求手输时间。确认后才回传，取消/Esc 不修改原值，关闭后恢复入口焦点。嵌套任务/子项弹窗内保持正确层级。
- 已移除手写的任务日历以及任务模块原生日期时间输入；不再复制日历网格或混用不同日期弹层。

2026-10-09 时间选择优化验收：`npm run typecheck`、`npm test -- src/renderer/src/components/Tasks`（6 文件、30 项）、`npm run build`、`node scripts/smoke-electron.js --task-edit` 和 `--task-scheduling` 通过。使用隔离数据，验证常用分钟切换、45→46 分钟键盘调整、返回日历保留选择及焦点、确认持久化、取消/Esc、无效日期与开始/截止标签；1100/375 宽、深浅主题检查日历/时分切换前后的弹窗坐标与高度一致，并人工查看截图。截图在 `artifacts/time-picker-improved-20261009/`，日志在 `temp/time-picker-improved-smoke.log` 与 `temp/time-picker-scheduling-smoke.log`。本轮仅调整用户待办公共时间控件，未涉及联系人任务或执行引擎；不代表真实模型与全天运行验收。构建仍有既有的大 chunk 提示。

## 时间安排区间（2026-10-09）

- 时间安排统一显示「开始 — 截止」，始终保持左侧开始、右侧截止，两端在有值和无值时均保留标签；已有值同时展示日期和时分，未设置的一端显示「未设置」。
- 开始与截止分别直接打开日期时间选择器，日历选择写入对应字段；提醒和重复移到外面各自独立成行，不再藏在时间弹层的标签页中。沿用开始不能晚于截止的保存校验。

## 子项编辑与默认展开（2026-10-09）

- 字段配置新增「子任务默认展开」，按当前视图保存，列表和看板共用；仍可单独展开、收起某个任务的子项。
- 任务表单属性行间距收紧；子项区域可折叠，采用无边框标题与列表，不使用分组框样式，仅在标题右侧提供新增图标按钮，打开带名称、截止时间、提醒的弹窗，支持保存、取消与 Esc；Esc 只关闭子项弹窗，父任务编辑内容保留。
- 移除底部添加栏、行内新增按钮、Enter 插入子项和冗长说明。子项拖动柄使用小图标，拖动柄与删除按钮仅悬停或键盘聚焦时显示（触屏常显）。子项截止时间使用跟随主题的日历与时分选择器，不调用系统原生日期弹窗。子项通过拖动柄调整顺序，也可聚焦拖动柄后用 Alt + 上下方向键排序；顺序随父任务保存，取消父任务编辑不写入。
- 新增子项保存到当前任务草稿，父任务保存失败时保留草稿供重试。已有子项名称、勾选、截止时间和提醒继续可编辑。

## 我喜欢的清单（2026-10-09）

- 侧栏分组和清单列表上方仅在存在喜欢的清单时显示「我喜欢」文字标签和清单；不提供折叠行，没有喜欢的清单时整个区域隐藏。
- 每个清单菜单提供「标记为喜欢／取消喜欢」，喜欢区域复用普通清单行，保留原图标，悬停或键盘聚焦时显示原菜单按钮，菜单内提供取消喜欢及原有清单操作。这里是原清单的快捷入口，不复制任务、不改变所属分组；默认清单同样支持。
- 喜欢状态写入数据库，重启和备份恢复后保留；归档或删除后隐藏，恢复原清单后重新显示。保存失败保留原状态并显示错误。
- 数据库 v12 为清单增加喜欢标记，旧清单默认未标记，继续支持 v9/v10/v11 备份。启动时即使版本号已是 v12，也检查并补齐缺失的喜欢字段，兼容同版本开发数据。
- 验证覆盖数据库升级、重开、备份与回收站恢复；`--task-views` 界面专项覆盖标记、快捷访问、归档恢复、渲染器重载和取消喜欢。

## 自定义视图：范围、筛选与排序（2026-10-09）

- 视图是分组、清单范围与筛选、排序配置的组合。新建/编辑弹窗只提供名称、分组、清单；两个范围下拉默认「不限」。不在弹窗中另做时间依据、状态、关键词、自定义字段或排序表单。
- 新建后进入该视图，通过已有「筛选」「排序」「任务完成状态」工具栏调整。自定义视图的优先级、清单、截止范围筛选直接保存到视图记录；排序和完成状态复用已有按视图持久化的界面配置。切换视图、重开应用后恢复各自设置。
- 筛选保存期间禁用重复操作；写入成功才更新生效条件，失败显示错误并保留此前已保存的条件，可重试。清除筛选只清除当前视图的筛选，不改变其分组范围。
- 「保存为新视图」沿用同一简洁弹窗，继承当前范围、筛选、排序和完成状态；不要求重复填写条件。普通新建默认无优先级/截止限制。
- 分组指定、清单不限时动态包含该组的清单，新建或移入的清单自动纳入。选择分组后，清单下拉只列出该组清单；切换分组清除不属于新范围的选择。旧多清单条件继续保留，用户明确选择某清单或不限时才替换。
- 新建/编辑同一弹窗，保留保存、取消、Esc 与失败提示；无快速新建、多选、批量操作、筛选条件标签。此前尝试的复杂时间/字段查询表单已撤回，不作为后续设计依据。
- 视图分组由数据库 v11 引入；筛选复用已有列，排序与完成状态随任务界面配置备份，不新增通用查询引擎。
- 验证入口：`npm run typecheck`、`npm test -- src/main/tasks src/shared/tasks.test.ts src/renderer/src/components/Tasks`、`npm run build`、`node scripts/smoke-electron.js --task-views`。Electron 专项覆盖简洁表单、分组/清单、筛选即时保存、视图切换、排序继承、保存为新视图和渲染器重载；截图在 `artifacts/task-view-toolbar-20261009/`，使用隔离数据。

2026-09-29，工作区 `ChouYu-task-edit`，分支 `feat/task-edit-experience`。

- 新建与编辑任务：关闭按钮、取消、遮罩和 Esc 检查未保存修改；未添加的子项输入也参与检查。取消放弃后继续编辑，确认放弃才关闭。保存失败沿用原表单保留输入。
- 列表与看板：点击优先级或截止时间打开单字段编辑框；未设日期时可设置截止时间。只提交对应字段，日期联动由原有存储逻辑处理。改期或清除前显示提醒、重复规则的影响。
- 单字段编辑失败保留输入；保存前重新读取任务，发现内容变化时提示重新打开。此检查不是数据库原子版本锁。
- 未增加今天页过期提示、筛选条件标签、快速新建、多选或批量操作。排除要求已写入 AGENTS.md。

## 卡片子项操作

- 列表、看板点击子项进度展开步骤；点击名称或复选框可完成、恢复一个子项，支持键盘空格操作。展开区域不会触发父卡片编辑或拖拽。
- 写入期间显示保存状态并防止重复提交；失败不改变勾选结果，显示错误并允许重试。
- 新增单子项状态 IPC，在数据库事务中读取最新子项再更新指定状态，保留其他子项、日期、提醒及其发送记录。勾完子项不自动完成父任务，也不生成重复任务的下一期。
- 修复原有调度器仍发送已完成子项提醒的问题；恢复子项后可发送尚未发送的到期提醒，已发送提醒不重复发送。
- 子项日期、提醒和内容仍在完整任务表单编辑。
