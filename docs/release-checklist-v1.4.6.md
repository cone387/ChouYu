# ChouYu 1.4.6 发布验证

## 改动范围

自动更新服务、IPC/preload、顶部提示和设置“关于”页。后台检测和下载不弹系统对话框，明确点击后先通过现有退出保存流程，再由更新器启动安装。普通退出不自动安装。任务执行与聊天逻辑不变。

## 本地验证

- 状态服务先补充测试并确认缺少实现的失败，再完成实现。覆盖启动/周期/唤醒、并发去重、重复事件、下载失败重试、保存取消、延迟快照、窗口销毁和安装交接失败恢复。
- 全量 319 个测试文件、2,394 项通过；17 文件、62 项按原配置跳过。
- 类型检查与生产构建通过。
- 独立更新界面冒烟通过，覆盖真实 preload/React、后台检查、进度、重试、晚打开关于页、三种模式、375/600/1024 视口与亮暗主题。截图 `artifacts/quiet-updates-ui/`。更新 IPC 使用隔离夹具，不下载或安装真实更新。
- 独立代码审查发现的 macOS 提前退出和跨周期下载丢失检查问题已修复并复核。安装交接失败会重新打开可用应用，在界面提示重试。
- 最终新增 Enter 键真实输入验证通过。首次脚本仅发送无字符的 CDP Enter 未触发浏览器默认按钮动作；补齐焦点模拟与 Enter 字符后通过，产品按钮未增加自定义按键处理。
- 首次完整桌面回归在既有任务助手“隐藏后等待授权 66 秒”处失败。该场景单独复测通过，原日志保留在 `artifacts/quiet-updates-full-smoke.log`，专项日志为 `artifacts/quiet-updates-task-assistant.log`；尚不能据此宣称该间歇性失败根因已解决。
- 第二次完整桌面回归在长聊天滚动到底部等待处超时，日志 `artifacts/quiet-updates-full-smoke-recheck.log`。本轮未修改授权或滚动代码，不将更新专项通过当成完整桌面通过；正式发布仍必须通过干净构建机上的完整质量和成品验收。

## 发布门槛与边界

沿用标签流水线的质量检查、双平台构建、SQLite、Windows 真实安装文件校验和数据保留、完整桌面、DSH、旧数据升级及联系人恢复验证；新增 Windows/macOS 成品更新界面冒烟。

本机为 Windows，macOS 原生更新交接依据本地 electron-updater 实现修正，并由平台构建和界面验证补充；尚未实测两台平台从本版升级到未来正式版的完整在线自动更新。界面夹具测试不替代该端到端验证。正式发布结果待流水线完成后补录。
