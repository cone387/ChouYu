08 / ARCHITECTURE / 聊天与任务

ChouYu 的安排、问候与晨报

定时安排和主动陪伴如何引用真实工作，并进入共同聊天体验。

横向滑动查看完整图面；带链接的模块可继续展开。

如何读这张图

长期安排由 AssistantRoutineService 保存和调度；问候、回来检查由 CompanionBriefing 维护变化基线与回执。

工作检查只读联系人真实任务、成果和待处理事项；不能把聊天承诺当进展，不能自动代答。

晨报与检查消息经公共投递进入 ChouYu；普通提醒可直接生成文案，不要求每次都调模型。

范围与验证边界

提醒、工作检查不是同一条固定流水线。已支持的周期与缺口以任务规范为准；不声称退出或休眠期间仍在运行。
