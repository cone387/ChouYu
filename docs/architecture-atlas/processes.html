如何读这张图

主窗口禁用 Node 集成并启用沙箱与上下文隔离；Renderer 通过 preload 与主进程通信。

AgentWorkerRPC 管理 utilityProcess 的请求与响应，执行结果再由主进程投递。

JournalService 在主进程持有一个 worker_threads 工作线程，日志数据库操作由 worker 承担。
