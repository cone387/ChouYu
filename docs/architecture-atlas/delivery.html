如何读这张图

成果版本与任务通知快照在 AgentStore 的同一 SQLite 事务内创建；事务失败不能提前交付。

主进程 appendAgentNotice 与 appendAssistantMessage 适配到同一持久投递函数。

跨 SQLite 和 JSON 的重试用稳定回执去重；读消息与处理交互事项是两种状态。
