Mem0 完整远端列表作为配套修复保留：2026-09-09 源码核对确认，设置页 `memory.list` 通过 IPC 调用 provider 的 `list`，Mem0 继承 SQLite 列表实现；界面的刷新只重读缓存。聊天召回使用 `searchRemote` 请求远端并缓存命中，新增/编辑/删除使用远端确认接口。因此缺口是管理列表的完整读取、分页及远端变更刷新，并非 Mem0 未接入。远端列表获取失败或未取完所有页时，不应据此清除缓存。

## 迭代规则

1. 每个阶段先补验收标准，再实现功能。
2. 涉及外部网络、密钥或用户数据的功能必须有显式开关和失败恢复路径。
3. UI 改动必须同时覆盖窄屏、暗色模式、键盘焦点和减少动画。
4. 新功能合并前至少通过类型检查、单测、构建和 Electron 冒烟测试。
