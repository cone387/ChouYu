# ChouYu 迭代路线

更新日期：2026-09-07

当前版本：`1.2.0`（已发布）

## 下一版优先计划（2026-09-07 校准）

工作区版本为 `1.3.0-rc.3`。最新界面改动尚未包含在已有候选安装包中。以下为下一批建议顺序，未开始实现；外部环境验收按用户要求暂缓。

1. **记忆列表可信度**：Mem0 从远端读取完整列表并处理分页，明确加载失败、缓存与更新时间；刷新后远端删除的条目不再残留。当前入口已直达记忆库，但 Mem0 展示的仍是缓存。
2. **记忆管理体验**：点击状态数量筛选、明确空列表与无搜索结果的区别、提供刷新；对 Mem0 不支持的本地操作按能力隐藏。验收覆盖本地与远端模式的查看、搜索、编辑和删除失败恢复。
3. **聊天体验收尾**：覆盖输入区拖拽高度在小窗口、附件展开、切换会话和重启后的表现，统一剩余搜索框与分隔线样式。
4. **候选包更新**：以上收敛后重新生成安装包及哈希，确保安装包包含最新 UI。干净 Windows、多屏 DPI、真实 Claude 和更新链路验收继续单独记录，不阻塞当前界面迭代。

本批已完成：输入区上沿拖拽并记住高度、分隔线与背景统一、普通会话列表展开时 Esc 直接关闭面板、设置能力/插件入口平铺、记忆中心默认显示列表及状态数量。

这份路线把当前功能状态、发布前验收和后续能力拆成可独立验收的阶段。每个阶段完成后再进入下一阶段，避免同时引入多个高风险变量。

## 当前基线

### 已完成

- 桌面宠物、拖拽吸附、点击穿透、托盘和全局快捷键
- OpenAI-compatible / Claude 流式聊天、模型诊断和配置引导
- 多会话、Markdown、附件、截图、剪贴板快捷操作
- 工具调用、逐次授权、风险分级和插件工具
- SQLite 长期记忆、Embedding、冲突处理、版本历史、主题聚类和导入导出
- Mem0 Platform / Self-hosted 远程主记忆引擎
- 自适应聊天/设置面板、暗色模式、焦点样式、减少动画和设置导航搜索

### 工程门禁

- TypeScript 类型检查通过
- Vitest 单元测试数量以本地与 CI 最新运行结果为准，避免手工计数过期
- Electron 生产构建通过
- Electron 启动冒烟测试通过

## 迭代规则

1. 每个阶段先补验收标准，再实现功能。
2. 涉及外部网络、密钥或用户数据的功能必须有显式开关和失败恢复路径。
3. UI 改动必须同时覆盖窄屏、暗色模式、键盘焦点和减少动画。
4. 新功能合并前至少通过类型检查、单测、构建和 Electron 冒烟测试。
