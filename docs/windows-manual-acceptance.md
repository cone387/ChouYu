## 干净安装和卸载

1. 在干净 Windows 测试机或还原快照后的 VM 上记录系统版本、账户权限与 OCR 语言包；核对安装包哈希。
2. 使用普通用户安装到含中文与空格的目录。记录安装向导、快捷方式、开始菜单和首次启动结果。
3. 首次启动不配置 API，确认配置引导、退出与再次启动正常；之后用测试服务完成一轮对话。
4. 新建两段合成会话，其中一段含图片及超过 500 条消息；编辑一条记忆、保存设置，退出再启动。核对正文、图片、活动会话和设置未丢失。
5. 启用开机自启，注销并重新登录；确认只启动一个实例。关闭开机自启，再次注销登录，确认不再启动。
6. 退出应用后卸载。检查应用目录、快捷方式与自启入口；记录卸载器是否保留用户数据。重新安装并确认数据保留行为符合实际选择，不预设“卸载就删数据”。

## 升级与更新

1. 还原干净快照后安装已发布的 1.2.0，创建合成会话、图片、记忆与配置，退出应用并保留测试数据备份。
2. 用 rc.3 安装包覆盖升级；核对版本、配置、图片及记忆，确认仅出现一次迁移且旧数据仍可恢复。
3. 在含中文用户名/目录的账户重复关键步骤。模拟磁盘写入失败时，确认应用提示未保存且不会覆盖现有有效文件。
4. 自动更新是单独门禁：需要维护者控制的测试更新源/测试版本，验证发现、明确下载、取消或下载失败、完整性校验、重启安装及数据保留。手动覆盖安装不能替代自动更新验收；当前候选没有发布到公共更新源。

## 多屏与缩放

在 100%、125%、150% 缩放下分别测试，再覆盖左右排列、负坐标、副屏高于主屏、不同缩放混用和运行中拔掉副屏。

每组检查：宠物拖拽与吸附、聊天/设置越界修正、跨屏窗口截图和区域截图坐标、快捷键注册失败反馈、点击穿透开关恢复、显示器移除后窗口可达。记录实际显示器 bounds/workArea/scaleFactor，并对应用窗口截图；等效视口截图不能替代这一项。
