# ChouYu 1.4.9 发布验证

## 范围

包含 v1.4.8 后的逐项提醒、紧凑通知卡片、独立阅读标识、会话日期修正、A2UI 成果阅读及 14 款内置联系人头像。旧头像选择区与 emoji 回退已移除，历史联系人字段兼容映射，不删除会话数据。发布说明见 [v1.4.9](releases/v1.4.9.md)。

## 发布阻塞修正

此前主干 A2UI 提交的 Quality 在 npm audit 阶段失败：Zod 3.25.76 命中 [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)。本版升级 Zod 4.6.7，并统一依赖树的 Zod 版本；A2UI React/web_core 升级至 0.16.1。没有降低 audit 阈值、跳过检查或改用旧解析运行时。

A2UI 的组件结构反射仍依赖旧式 `_def` 描述。仅对应用自有闭合阅读目录添加 `readingSchema` 元数据适配，实际解析与约束仍由 Zod 4 的 `_zod` 执行。目录只接收主程序生成的静态 children 列表，显式上限 300；未实现动态绑定或任意模型组件。未知 schema 类型拒绝接入。真实 SDK 渲染、目录导航与阅读位置测试红→绿；额外测试确认 10,000 元素输入在逐项解析前拒绝，数值范围与枚举仍有效。独立审查未发现发布阻塞。

安全检查：主项目高危阈值通过，仍有 electron-builder/minimatch 依赖链的 6 项 moderate 报告；DSH 运行时 audit 为 0。未通过强制降级打包工具来清理 moderate 报告。
