# 联系人工作设置验收（2026-10-09）

本次优化现有工作设置 Tab。工作方式、消耗上限、通知、资料与协作权限、工作时间全部展开；选择即保存，数字直接输入并在本行应用，支持 Enter。取消前置修改和全局保存步骤，保留原任务单描述弹窗及共用任务界面。

工作方式切换保留正在执行和等待回复的轮次；截止时间和连续失败阻塞自动调度，不改写用户选择的工作方式。每日工作 Token 上限与新任务累计默认上限独立保存，默认只复制给新任务；已有任务通过描述中的明确数字调整。原调用次数保护继续生效。
