# 稳定性收尾验收（2026-09-23）

范围：当前 `1.3.4` 工作区（含原有未提交的 AI 任务助手改动）。不发布、不操作真实在线账户，不修改用户活动记录设置。验证使用独立用户目录与本地模拟服务。

## 修复内容

1. **窗口拖拽测试误命中。** 原测试用小数坐标判断顶栏命中，随后取整发送输入。在本机缩放下，`(1129, 174)` 实际命中圆角外的 `.app-container`，没有触发拖拽。现在先选择整数点并验证邻近点位于顶栏内部，再发送真实 Electron 输入。仍检查越过视口边缘、隐藏/恢复、最大化/还原及模式切换，不放宽位置断言。失败时输出指针事件与实际边界。
2. **隐藏窗口停止出帧。** 本次观察到隐藏测试窗口的逐帧采样停滞。仅在 smoke 模式串行调用 `capturePage({ stayHidden: true, stayAwake: true })` 保持测试窗口绘制，结束时清理；不替换 `requestAnimationFrame`，不改变生产窗口行为。Electron 对后台节流与隐藏状态的约定见 [BrowserWindow 文档](https://www.electronjs.org/docs/latest/api/browser-window#page-visibility)。
3. **保留页面的过期断言。** 日志页切换日期后，隐藏概览会延迟加载；测试改为等待可见内容。后台回复先等待流结束，再回到聊天检查新消息提示、原阅读位置与跳转结果，符合现有隐藏页暂停测量的行为。
4. **删除会话后的异步保存。** 应用新工作区时清理已删除会话的消息缓存，避免关闭面板时再次写入；自动保存与卸载保存捕获 Promise 拒绝，磁盘失败仍由现有持久化状态提示。通讯录回归增加“删除角色 → 关闭聊天 → 等待自动保存窗口”的检查，断言没有未处理拒绝、没有会话复活。
5. **验收可诊断性。** 增加 `--chat` 专项入口、阶段开始/完成耗时、renderer 错误日志、逐帧断言异常传播与 5 秒限时。成功信息改写 stdout，避免 PowerShell 将成功消息当作原生命令错误。
6. **性能观测。** 隔离日志循环增加主线程事件循环延迟的累计样本数、均值、P95 和最大值；无样本时保持 null，不把缺测当成零。
7. **测试阶段的会话隔离。** 完整回归中，日志阶段留下已挂载的聊天面板；任务助手在主进程切换夹具会话后，界面仍绑定上一会话，导致退出迁移检查发现原有 2 条消息变成 23 条。任务助手现在在创建夹具前卸载面板并排空保存，重新挂载后确认选中的夹具会话，清理后断言原会话消息完全不变；退出迁移仍要求原有 2 条消息与标题一致。

## 隔离循环实测

机器环境：Windows、Electron 44.2.0、Node 24.20.0。两次运行均为隐藏合成窗口、禁用 GPU，每 5 秒一轮，包含真实本地 OCR 与 SQLite worker。原始汇总和源码 hash 已保存到 [测量记录](evaluations/stability-soak-2026-09-23.json)。

| 指标 | 10 分钟运行 | 增加延迟指标后的 5 分钟运行 |
| --- | --- | --- |
| 成功 / 失败 | 120 / 0 | 60 / 0 |
| 存储/OCR/采集器重启恢复 | 4 次（每 120 秒） | 4 次（每 60 秒） |
| 指标采集失败 | 0 | 0 |
| 单轮耗时 P95 | 607.38 ms | 857.97 ms |
| Electron 总工作集首 / 尾 | 432.93 / 444.70 MB | 289.20 / 292.54 MB |
| 事件循环 P95 / 最大值 | 未采集 | 33.39 / 473.17 ms |

延迟直方图分辨率为 20 ms，记录调度间隔，不能将整个间隔解释为额外阻塞时间。运行期间有构建与界面测试并行，两个独立进程的内存值不能当作优化前后对比；473 ms 峰值仍需在受控真实负载下定位。结果证明本次有限循环与脚本化恢复成功，不证明全天无泄漏、无卡顿。
