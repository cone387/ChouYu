# 当前功能状态

更新日期：2026-08-31

当前开发版本：`1.2.0`（记忆质量迭代，开发中）

## 已可用

- 桌面悬浮宠物、拖拽、边缘吸附、点击穿透和位置记忆
- 全局快捷键唤出、托盘菜单和角色右键菜单
- 托盘图标单击、双击和菜单入口统一打开聊天面板，不再控制桌面宠物显示/隐藏
- OpenAI 兼容接口与 Claude 流式对话，AI 网络请求运行在 Main Process
- Provider 连接诊断、`/v1` 自动修正、认证/网络/响应错误区分
- 主界面与设置页共享的可搜索模型选择器，支持键盘导航和无效模型提示
- Markdown、代码块复制、每个会话最多 500 条消息持久化
- 多会话工作区：新建、切换、搜索、重命名、删除确认和 Markdown 导出
- 会话列表宽度支持拖拽调整并持久化；不同会话的 AI 回复可并行在后台继续，互不覆盖
- 聊天内容区宽度支持独立拖拽调整并持久化，拖拽边界仅显示调整光标，不显示彩色高亮线
- 聊天、会话列表和设置面板首次打开默认居中；用户拖动后保存位置，并在显示器尺寸变化后自动夹紧
- 旧版单会话数据自动迁移到多会话存储
- 首次 AI 配置引导和上下文截断提示
- 记忆写入模式：默认自动写入，支持逐条确认或关闭写入；冲突候选始终需要用户决策
- 自动写入支持谨慎、平衡和宽松三档置信度；默认平衡，低置信度候选进入待确认
- 记忆证据过滤会忽略疑问句、玩笑、假设、第三方转述和无效姓名；不确定表述会降级审核
- “我是谁 / 我叫什么”等身份问题会跨会话优先召回人物记忆，启动维护会归档旧版误提取的无效姓名
- 记忆中心默认只显示启用记忆，待确认和已归档内容可通过状态筛选单独查看
- 停止生成、失败重试和重新生成
- 模型选择器，以及 `/model 模型名` 快速切换
- idle / thinking / talking / happy / sleeping 角色状态
- SOUL.md 人格内容编辑
- 图片与文本附件、文件拖拽、区域截图
- 窗口/屏幕选择截图，以及基于视觉模型的 OCR、总结和翻译快捷操作
- 本次运行最近 5 张截图复用和图片附件快捷处理
- 剪贴板翻译/总结/询问入口、开机问好和久坐提醒
- OpenAI 与 Claude 通用工具调用循环，不支持工具的模型自动回退普通聊天
- 工具风险分级、逐次授权、60 秒超时拒绝和对话执行时间线
- AI 工具操作权限模式：默认确认、自动审核（安全/读取自动执行，写入仍确认）和完全访问
- 内置当前时间、读取/写入剪贴板、选择文本文件、列出窗口工具
- 设置中可完全关闭 AI 自动工具调用
- 插件自动注册为 AI 工具，外部操作统一强制逐次授权
- 设置页工具目录：来源、风险、授权模式与逐工具启用/禁用
- SQLite 本地长期记忆与可插拔 MemoryProvider 接口
- 明确表达的事实/偏好/人物/项目/工作方式候选提取与逐条确认
- 密码、API Key、Token、JWT 默认阻止写入
- 关键词、重要度、时间和使用频率混合检索并注入 Prompt
- 回答下方可展开查看实际使用的记忆来源
- 设置页记忆中心：搜索、筛选、添加、确认、编辑、删除、导出和忘记全部
- 独立 OpenAI 兼容 Embedding Provider，可留空复用主 AI Provider
- SQLite Float32 向量索引、连接测试和现有记忆批量重建
- 55% 关键词/结构化分数与 45% 向量相似度混合排序
- Embedding 不可用时自动降级为关键词检索
- 同类型事实、偏好、项目和工作方式的矛盾/更新候选检测
- 冲突候选必须由用户选择“替换旧记忆”“两条都保留”或“拒绝新记忆”
- 替换时归档旧记忆并移除旧向量，不会静默覆盖
- 编辑、替换和恢复前保存版本历史，支持卡片内确认恢复
- 可配置 50–2000 条记忆容量预算，超出后按重要度、使用时间和反馈归档低价值项
- 新记忆可配置默认有效期，过期记忆自动归档并移除向量索引
- 记忆中心提供低价值建议、多选批量归档、归档原因和恢复使用
- 回答的记忆来源支持“有帮助 / 不准确”反馈，幂等记录并参与后续检索排序
- 本地主题聚类：按类型和关键词相似度分组，展示主题摘要及原始来源
- 检索结果可压缩为主题摘要，Prompt 保留全部原始记忆 ID，支持来源反馈传播
- 聊天记录显示压缩前后的记忆数量和主题来源
- 人工主题：从已确认记忆中多选同类型条目合并，并可拆分自动/人工主题
- 单条记忆可设置永久、7 天、30 天、90 天、180 天或 1 年有效期
- JSON 导入在写入前预览新增、重复、矛盾和更新，逐条选择并存、替换或跳过
- 本地统计概览展示类型分布、近 8 周新增、归档构成、反馈和压缩量
- “不准确”反馈后可直接打开记忆中心并定位原始来源进行修正
- Mem0 主记忆引擎：连接测试、按 User ID 隔离和主引擎单选使用
- Mem0 API Key 使用 safeStorage 本机加密；不提供后台同步、备份或迁移
- 移除百炼和 `qwen-plus` 的首次启动兜底；Base URL、API Key、模型缺一不可
- 未完成 AI 配置时不能发送普通对话，也不能永久跳过配置提醒
- 独立服务能力注册表：记忆引擎和 Embedding 均由 Main Process 能力插件提供
- 内置 ChouYu SQLite、OpenAI-compatible Embedding、Mem0 Platform 和 Mem0 Self-hosted 能力
- Mem0 Self-hosted 使用源码对应的 `/memories` 与 `X-API-Key`，可连接 `localhost:8888`
- 记忆引擎插件缺失时安全退回 SQLite；Embedding 插件失败时继续退回关键词检索
- 聊天面板全面禁止横向滚动：长文本、代码块、表格、URL、截图菜单和模型菜单均自适应换行/视口宽度
- 代码块保留复制功能但改为换行显示，最近截图缩略图改为多行排列
- 能力目录提供当前选中状态、网络访问和是否发送记忆数据的诊断元数据
- 工具栏恢复单行布局；截图菜单保留向上展开能力，不再被聊天容器裁切
- AI 设置“测试连接”一次展示聊天 Provider 与 Embedding 能力诊断；未配置时不发起无意义请求
- 诊断结果明确区分可用、待配置、未启用和不可用，并显示向量维度而不暴露密钥
- 独立能力中心页面，统一展示记忆引擎和 Embedding 的启用状态、网络访问和数据发送边界
- 能力选择入口与记忆中心保持一致，支持从总览直接跳转配置
- 新增 JSONL 进程能力协议清单校验，为 Mem0 OSS 等重型可选能力预留隔离边界，不增加主程序依赖
- Memory Explorer 记忆库视图：总览统计、类型快捷筛选、搜索、最近更新/重要度/使用次数排序
- 独立记忆工作区：从聊天顶栏、设置导航或 `/memory` 进入，按总览、待处理、记忆库、整理和连接分区
- 待处理视图支持配置显示范围（仅待确认与冲突 / 全部记忆），选择会保存在本机
- 记忆卡片支持展开查看来源与依据、置信度解释和远程数据边界，默认保持紧凑
- Mem0 模式下聊天检索直接走远程主引擎；本地记忆库、Embedding、主题聚类、生命周期和待处理操作仅用于 SQLite 模式
- Mem0 Self-hosted 连接测试同时验证远程列表与 `/memories/search`，并区分超时、连接失败、鉴权失败和服务版本不兼容
- 聊天中的“不准确”反馈可直接打开独立记忆工作区并定位原始记忆
- 记忆卡片集中展示状态、有效期、反馈、来源和版本历史，支持新增、编辑、归档恢复、删除和导出
- 卡片内操作保留二次确认和异步状态，不依赖顶层弹窗
- 设置面板不再固定 440px 高度：桌面最多 760×640，按视口自动收缩
- 设置导航支持搜索、方向键、Home/End 和 Esc 清空；人格编辑器扩大并使用细滚动条
- 聊天面板高度和会话列表展开状态会持久化，并在显示器尺寸变化后自动夹紧到可用范围
- 输入框只在进入聊天、新建/切换会话或关闭阻塞流程时获取焦点，不再用延迟重试抢夺其他控件焦点
- 设置内容区独立纵向滚动并禁止横向溢出；窄屏导航与内边距自动收敛
- 长内容、Markdown 代码/表格、超长 URL 的聊天布局回归保护持续生效
- 插件框架与 BBTalk 内置插件
- 开机自启、检查更新和下载进度反馈
- 更新错误会按权限、版本不存在和网络故障分类提示，不直接暴露 Token/鉴权原始错误
- API Key 与插件密钥的本机安全存储（系统支持 `safeStorage` 时）
- 仅宠物模式置顶；聊天和设置面板按普通窗口层级显示
- 隔离临时用户数据的开发产物与打包产物启动冒烟测试
