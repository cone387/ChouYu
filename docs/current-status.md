# 当前功能状态

更新日期：2026-08-26

## 已可用

- 桌面悬浮宠物、拖拽、边缘吸附、点击穿透和位置记忆
- 全局快捷键唤出、托盘菜单和角色右键菜单
- OpenAI 兼容接口与 Claude 流式对话
- Markdown、代码块复制、最近 30 条消息持久化
- 模型选择器，以及 `/model 模型名` 快速切换
- idle / thinking / talking / happy / sleeping 角色状态
- SOUL.md 人格内容编辑
- 图片与文本附件、文件拖拽、区域截图
- 剪贴板翻译/总结入口、开机问好和久坐提醒
- 插件框架与 BBTalk 内置插件
- 开机自启、检查更新和下载进度反馈
- API Key 与插件密钥的本机安全存储（系统支持 `safeStorage` 时）

## 需要真实环境验收

- 不同 OpenAI 兼容服务和 Claude 官方接口的模型列表、流式响应兼容性
- BBTalk 登录、Token 刷新和发布
- Windows 安装包、开机自启和自动更新
- 多显示器、缩放比例和不同分辨率下的截图与面板定位
- 快捷键与其他软件冲突时的恢复行为

## 尚未实现

- OCR、滚动截图、录屏和活动窗口理解
- SQLite/向量检索式长期记忆
- 通用 Function Calling / Agent 工具系统
- 语音输入、TTS、3D/VRM 角色
- 插件市场、多角色和多设备同步

## 工程验证

当前自动化质量门禁包括 TypeScript 类型检查、Vitest 单元测试和 Electron 生产构建。单元测试覆盖配置归一化、Prompt 构建、AI 流解析与 URL 校验、附件限制和角色状态机；桌面交互仍需实机验收。
