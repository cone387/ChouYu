# 当前功能状态

更新日期：2026-08-27

当前开发版本：`0.7.0`（对话工作区迭代，尚未创建 Git 标签或 GitHub Release）

## 已可用

- 桌面悬浮宠物、拖拽、边缘吸附、点击穿透和位置记忆
- 全局快捷键唤出、托盘菜单和角色右键菜单
- OpenAI 兼容接口与 Claude 流式对话，AI 网络请求运行在 Main Process
- Provider 连接诊断、`/v1` 自动修正、认证/网络/响应错误区分
- 主界面与设置页共享的可搜索模型选择器，支持键盘导航和无效模型提示
- Markdown、代码块复制、每个会话最多 500 条消息持久化
- 多会话工作区：新建、切换、搜索、重命名、删除确认和 Markdown 导出
- 旧版单会话数据自动迁移到多会话存储
- 首次 AI 配置引导和上下文截断提示
- 停止生成、失败重试和重新生成
- 模型选择器，以及 `/model 模型名` 快速切换
- idle / thinking / talking / happy / sleeping 角色状态
- SOUL.md 人格内容编辑
- 图片与文本附件、文件拖拽、区域截图
- 剪贴板翻译/总结入口、开机问好和久坐提醒
- 插件框架与 BBTalk 内置插件
- 开机自启、检查更新和下载进度反馈
- API Key 与插件密钥的本机安全存储（系统支持 `safeStorage` 时）
- 仅宠物模式置顶；聊天和设置面板按普通窗口层级显示
- 隔离临时用户数据的开发产物与打包产物启动冒烟测试

## 需要真实环境验收

- 不同 OpenAI 兼容服务和 Claude 官方接口的模型列表、流式响应兼容性
- BBTalk 登录、Token 刷新和发布
- Windows 安装、卸载、开机自启和自动更新完整链路
- 多显示器、缩放比例和不同分辨率下的截图与面板定位
- 快捷键与其他软件冲突时的恢复行为

## 尚未实现

- OCR、滚动截图、录屏和活动窗口理解
- SQLite/向量检索式长期记忆
- 通用 Function Calling / Agent 工具系统
- 语音输入、TTS、3D/VRM 角色
- 插件市场、多角色和多设备同步

## 工程验证

当前自动化质量门禁包括 TypeScript 类型检查、31 项 Vitest 单元测试、Electron 生产构建和启动冒烟测试。单元测试覆盖配置归一化、Prompt 构建、AI 流解析与 URL 校验、Provider 模型诊断、模型搜索、会话标题/搜索/Markdown 导出、附件限制、回复重试与角色状态机。

启动冒烟测试会在临时用户目录中放入 V2 单会话数据，并验证其自动迁移到 V3 多会话存储。`0.6.0` 的 Windows 发布候选记录仍保留在 [0.6.0 发布检查清单](release-checklist-v0.6.0.md)；`0.7.0` 尚未生成正式安装包。
