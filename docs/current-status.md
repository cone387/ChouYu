# 当前功能状态

更新日期：2026-09-23。

代码版本为 `1.3.4`（以 `package.json` 为准）。AI 任务助手与稳定性收尾已提交于 `fd45505`；工作区新增联系人 Agent 本地首版，尚未发布安装包。源码验证结果不能代表已发布版本。发布内容见 [v1.3.4 说明](releases/v1.3.4.md)，此前结果见 [稳定性验收](stability-acceptance-20260923.md)。

## 已有能力

- 桌面宠物、托盘、快捷键、亮暗主题、多角色与通讯录。
- 多会话流式聊天、全文搜索、Markdown、附件、截图、Windows 离线 OCR，以及 Provider 配置与诊断。
- 聊天持久化、附件独立保存、损坏隔离、备份恢复、保存失败提示和重试。
- 任务清单与分组、自定义视图、列表/看板、筛选排序、普通新建和单任务编辑、重复规则、提醒、历史与备份恢复。
- 本地 SQLite 长期记忆、可选 Embedding、来源追溯、冲突处理、版本历史，以及可选 Mem0 主引擎。
- 本地活动日志、画面/OCR、按日总结与问答、项目归档、踩坑手册、周报、语义查找、接续卡与收藏。
- 工具调用、授权预览、执行时间线、逐工具启用与插件能力注册。

## 当前工作区新增与修复

- [联系人 Agent](contact-agents-design.md)：LangGraph JS、独立执行进程、定时只读研究、SQLite 检查点、等待回复恢复、独立记忆及资料追溯。默认关闭；保持应用运行才可持续工作，关机常驻与云执行尚未实现。
- [AI 任务助手](task-assistant.md)：查询真实任务、读取详情、经确认修改或完成一个任务。校验内容版本，拒绝过期确认，一次请求最多一个任务写操作；真实在线模型验收仍待完成。
- Windows 鼠标穿透已移除全局鼠标转发路径，采用坐标轮询与状态同步。详见 [性能排查](performance-audit-2026-09-22.md)；长期卡顿的现场因果与全天复测仍未闭环。
- 稳定性收尾已通过完整 Electron 回归与退出迁移检查：修复测试窗口绘制、拖拽命中、保留页面断言与阶段间会话隔离，并清理已删除会话缓存及未处理的保存拒绝。逐项证据见本轮验收文档。

任务系统继续遵守 [AGENTS.md](../AGENTS.md)：不提供快速新建、对应快捷键、多选或批量处理；保留普通新建表单与单任务操作。

## 验证与边界

- 本轮最终检查：类型检查、89 个测试文件 / 761 项单测、本地记忆评测、生产构建和完整 Electron 回归通过。
- 两次隔离采集/OCR/存储循环共 15 分钟、180 轮、零失败，8 次脚本化恢复成功。主线程延迟与测量边界统一记录到本轮验收文档；有限循环不能替代全天真实使用。
- 尚需真实环境验收：长时间日常运行、多屏/DPI、睡眠恢复、真实屏幕捕获、不同在线模型、安装/卸载与自动更新。
- 性能后续重点：测量聊天全量 JSON 保存及同步落盘的主线程停顿；按实际大库负载决定独立 worker 或增量存储方案。当前未改动存储可靠性机制。
- 构建仍有入口 chunk 大于 500 kB 的提示；按需加载属于后续优化，不以打包体积直接推断实际启动速度。

## 后续方向

优先完成稳定性与交付验收，再完善现有聊天、任务、提醒和来源定位的衔接。语音/TTS、3D/VRM、插件市场与多设备同步尚未纳入本轮范围。

2026-09-08 及更早的版本、测试数量和分批记录已移至 [历史状态](current-status-history-20260908.md)，不作为当前完成度依据。
