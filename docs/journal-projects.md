# 项目归档进度

2026-09-09 完成数据层及日志 IPC，后续已接入“项目归档”视图。本阶段面向独立收藏的接续卡与书签，不代表已对所有原始活动、浏览器 URL 或 Git 记录完成归档。

项目保存名称、说明、归档状态和应用/标题包含规则，最多 100 个项目，每个最多 20 条规则。名称最多 80 字、说明最多 1000 字；名称按 Unicode NFKC 与小写规则检查重复。规则应用、标题分别最多 120 字，不能两项都为空。仅用字面包含匹配，不执行正则表达式或外部命令。

同一规则中的应用和标题必须命中同一条来源，项目的多条规则之间是“或”。匹配范围为收藏内的活动和画面标题，没有来源时仅使用收藏标题。归档项目不提供新建议；一个命中显示建议，多个命中保留歧义，不自动挑选。此逻辑未调用模型或发送内容到外部服务。

每份收藏可以手动指定一个项目、明确不归属，或清除手动覆盖以恢复规则建议。手动选择优先于规则变更，归档项目不丢失已有手动归属。删除项目只将其归属改为明确不归属，保留收藏及来源快照；删除收藏通过数据库触发器同步移除归属记录。普通日志保留期限不作用于这些独立项目表。

日志数据库升级为版本 8；新增项目与归属表及删除触发器，保留原有收藏数据。项目保存和归属修改使用 IMMEDIATE 事务。旧版本应用会根据版本保护拒绝打开该数据库，需要使用当前源码对应版本。
