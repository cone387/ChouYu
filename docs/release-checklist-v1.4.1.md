# ChouYu 1.4.1 发布验证

日期：2026-10-26。正式公开状态和双平台构建结果以 GitHub 的 `v1.4.1` Release 及对应 Actions 为准。

`v1.4.0` 在质量门禁失败，未公开；保留原标签，修复候选使用新版本号。418px 面板复现输入框 96→108→96px：聊天离页卸载工作栏，返回统计占位更新导致按钮换行。现保留工具栏 DOM/统计，隐藏时暂停查询并卸载详情子树；不保留顶层任务子弹窗。新增实际隐藏面板回归先复现残留弹窗，再验证修复；导航仍逐帧要求高度/滚动误差不超过 1px。

本地全量测试与 Electron 同时运行时，300 版本迁移测试用时 84 秒，超过原有 60 秒上限（其余 2190 项通过）。保留失败记录，后续采用不与 UI 回归争用资源的验证；不扩大测试超时。全量 UI 首次复测因旧断言把已关闭的保留 dialog 当成未关闭而失败，已改为验证记录设置弹窗卸载且不存在任何打开弹窗，截图操作仅选择打开的弹窗。

第一轮修复产物的完整 Electron 回归通过（存储、联系人、待办、供应商、聊天、活动记录、任务助手、后台任务及提醒）；418px 导航和 v1.3.4 升级也通过，模块边界和记忆合成评测通过。此前完整流程曾在任务完成回执处等待超时，单独复核及带诊断的完整复核通过，当时根因尚未确认；保留 `chouyu-release141-full.log` 与 `chouyu-release141-full-diagnostic.log`，后续定位见下文。独立审查提出的嵌套弹窗和隐藏订阅问题已修复，无剩余阻断意见。

成品复核的提醒用例曾在按钮仍 busy 时点击失败：变更事件可先更新“已安排”状态，再由 IPC promise 清除 busy。测试改为每次等待指定按钮可操作，保留保存值、取消、重启和任务完成后的失效断言；不改动产品提醒行为。

后续 CI 的完成回执诊断确认空正文与工具 waiting 状态：IPC invoke 结果可能先于排队的 stream/tool 事件到达，界面过早完成并移除监听及请求映射。真实 Electron 为首个拒绝场景延迟事件 60ms，稳定复现同样故障；新增 IPC 结束事件约定，界面同时收到调用结果和对应结束事件后才完成，失败与取消亦覆盖。根因现已确认，不再将这次回执超时仅视为环境偶发。相关 4 文件 23 项回归通过，类型检查通过，真实 Electron 和最终全量结果继续以日志/CI为准。

完整 UI 另一次在任务分组菜单失败，事件轨迹显示关闭键盘打开的任务弹窗后，恢复焦点触发的侧栏 scroll 晚于测试紧接着打开菜单，正常的 scroll 关闭行为将其关掉。该处自动化先等待关闭后的两帧布局，再开始下一次菜单操作；保留 popover 必须打开的断言，不改产品菜单行为。最终开发产物完整 Electron 回归通过全部阶段，包括延迟事件复现用例、66 秒审批等待和提醒；日志为 `chouyu-release141-stream-full-final.log`。正式成品仍由发布流水线独立验证。

- Windows / Node 24.15.0：包含回复竞态修复的全量测试 284 个文件、2198 项通过，61 项跳过（单独运行 61.80 秒）；类型检查通过，模块边界、记忆合成评测与构建沿发布准备流程复核。
- 应用及独立 DSH 运行时审计均为 0 个漏洞。应用锁更新 Electron 44.9.3、Vitest 5.0.5、Vite 7.3.7；DSH 维持 0.2.1-alpha.3，仅覆盖兼容主版本中的 Zod、undici、fast-uri、fflate、MCP client 安全更新，并同步 MCP core。
