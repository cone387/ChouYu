# 联系人技能接入验收记录

日期：2026-10-10。范围：用户确认的 SkillHub 商店、联系人独立配置、技能说明与文本参考资料加载。现行产品约定见 [联系人任务规范](contact-task-spec.md)，设计见 [接入设计](superpowers/specs/2026-10-10-contact-skillhub-design.md)。

本文按迭代记录历史验收；当前运行能力与未完成项以最后一节为准。

## 使用方式与实际行为

打开联系人 → 技能，默认展示按综合评分排序的技能市场，可直接浏览、筛选、翻页或搜索并安装技能，然后在技能库为当前联系人启用。首次安装自动准备商店组件，浏览目录无需 CLI。联系人详情和展开工作窗口复用同一组件。安装库共享，启用与停用按联系人保存；停用保留关联，移除关联后才能在无其他联系人引用时卸载。安装本身不启用技能。

技能正文及文本参考资料进入普通聊天、联系人后台工作、ChouYu 晨报及工作检查。后台每轮开始保存内容快照，恢复同一轮沿用原快照；新轮次直接读取最新配置，不依赖身份同步计时器。修改技能不重置人设、不取消当前任务。文件损坏、超出文本预算或保存冲突明确报错；即使文件损坏，仍可停用或移除关联。

首版每位联系人最多启用 8 项，合并正文最多 64000 字符，超出时拒绝启用而非截断。支持已有工具；不会赋予技能新的工具权限。含脚本、二进制资源、依赖清单或被识别为需要外部服务的技能保留安装记录并显示不可用原因。
