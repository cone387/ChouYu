# ChouYu v1.4.5

改善 Windows 安装负载：发布包不再携带 DSH 依赖的编译类型声明、JavaScript/TypeScript 源码映射和不匹配平台的 node-pty 二进制。运行时文件从 27,807 个减少到 14,807 个，减少 46.8%；解压后的运行时减少 92,260,456 字节。

保留运行代码、Windows x64 原生组件、运行时 TypeScript、资源和许可证，继续使用普通 EXE 安装与自动更新。沿用 1.4.4 的旧版本长路径升级修复。发布流水线新增实际安装后的完整文件校验和卸载数据保留检查。

具体安装耗时受磁盘、扫描软件及旧版本文件数量影响；从旧版首次升级仍需清理旧版的完整文件集合。
