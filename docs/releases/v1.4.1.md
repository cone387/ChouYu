## 更新内容

- 联系人任务统一使用共同的列表、详情和任务描述弹窗；ChouYu 的长期安排、晨报和日常提醒也在其中管理。
- 联系人按各自身份交流，写作、想法和评审直接交付实际内容；支持成果阅读、修订和来源定位。
- 支持通过自然语言设置明确的任务截止时间，以及按成功产出或送达次数结束安排。
- 展示联系人后台连接和任务实际执行状态，提供异常重试、成组备份及恢复后的资料和任务核对。
- 联系人资料增量同步，会话列表和历史正文按需加载，减少后台同步与备份对交互的影响。
- 修复小窗口切回聊天时输入框短暂跳动；隐藏聊天后同步关闭任务子弹窗并暂停工作栏查询。
- 用户待办支持按日程独立生成重复任务；改进自定义视图、单任务编辑、提醒送达和未读状态。
- Windows 内置 DSH 运行时，可分别为联系人聊天和后台任务选择执行引擎。

## 安装与更新

- Windows：下载 Setup.exe 安装包。
- macOS：下载 universal.dmg，支持 Intel 与 Apple Silicon；本版内置 DSH 运行时仅提供 Windows x64 版本。
- 已安装版本可通过「设置 → 关于 → 检查更新」升级。
- 本版包含存储迁移，升级前建议保留完整用户数据备份；联系人快照仅覆盖联系人任务与检查点，不替代完整备份。

## 已知限制

- 个别自然语言截止时间或次数描述仍可能解析失败；此时会提示失败，不会声称已保存。
- Windows 非正常退出后的数据库占用已增加有限重试和状态提示；持续占用时仍可能需要关闭占用程序后重试。
- 多个联系人继续共用后台进程，进程重启期间后台工作会短暂中断。
- Windows 成品验收中有一次 DSH 首次启动超时；包内协议、控制连接及新目录完整复核通过，但尚未确认该偶发超时的根因。
