## 更新内容

- 修复 Windows 从旧版覆盖升级时，因依赖文件路径过长导致安装失败、错误提示“ChouYu 无法关闭”的问题。
- 修复已内置在安装包中，直接双击安装即可，无需启动脚本、修改系统设置或清理聊天与任务数据。
- 保留原有应用关闭检查和升级失败回滚；安装完成后恢复临时目录环境，避免影响应用后续运行。
- 发布流程新增真实 Windows 安装、旧版升级失败回滚、修复后升级、数据保留及卸载检查。

## 安装与更新

- Windows：下载 `ChouYu-Setup-1.4.4.exe`。此前安装 1.4.3 失败的用户可直接使用此安装包覆盖升级。
- 已安装版本可通过「设置 → 关于 → 检查更新」升级。
- macOS：继续提供 Intel 与 Apple Silicon 通用 DMG；本次修复针对 Windows 安装器，macOS 功能不变。

## 验证与边界

- 本地安装器回归、完整应用测试（2,385 项）及 Windows 成品桌面冒烟通过。正式附件由标签流水线重新构建并验证，不复用本地临时修正版。
- 安装包仍未配置代码签名，macOS 未公证。真实 UAC 跨账户提升、UNC 临时目录及公共自动更新端到端未完成专项验收。
- 其他能力及已知限制沿用 [v1.4.3](https://github.com/cone387/ChouYu/releases/tag/v1.4.3)，包括尚未确定根因的偶发 DSH 通信断开；安装修复细节见 [验证记录](https://github.com/cone387/ChouYu/blob/v1.4.4/docs/windows-installer-long-paths.md)。
