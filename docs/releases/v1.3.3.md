## 更新内容

- 新增任务工作区：支持清单与分组、自定义视图、列表与看板、字段筛选、拖拽排序、循环任务和到期提醒。
- 优化通讯录：点击角色直接进入聊天，通过操作菜单查看详情、编辑或删除角色。
- 助手消息按问候、休息、返回提示、任务提醒、稍后提醒和异常通知显示不同图标、标签及配色，并保存消息类型。
- 全局搜索覆盖通讯录与任务，支持配置搜索快捷键；重新打开工作区时恢复上次页面。
- 优化工作日志存储配额管理和采集失败重试。

## 修复

- 修复 macOS 点击托盘图标同时弹出菜单和窗口：现在点击显示菜单，选择菜单项后再打开窗口。
- Esc 优先关闭弹窗，避免同时关闭主界面；修复关闭通讯录详情、任务弹窗、原生对话框和菜单后原按钮残留焦点高亮的问题。
- 补齐图片预览、清空记忆确认、截图及部分菜单的 Esc 处理。
- 改善任务视图状态保留、窗口布局和深浅主题下的控件显示。

## 安装与更新

- Windows：下载 Setup.exe 安装包。
- macOS：下载 universal.dmg，支持 Intel 与 Apple Silicon。
- 已安装版本可在「设置 → 关于 → 检查更新」中升级；开发模式不支持自动更新。
