## 更新内容

- 新增应用总览和全局 Token 使用统计，集中查看任务、联系人工作及模型用量。
- 联系人任务支持追踪原始聊天要求、后续调整、实际执行与成果版本，改进重试去重、来源定位和重启恢复。
- 新增独立「界面设计师」，为正式任务成果生成阅读界面，支持原文查看、界面调整、历史版本和新版切换；设计失败时保留原文。
- 成果界面验证覆盖长文中段和末尾，改进正文行长、章节阅读与滚动；模型不支持图片输入时给出明确提示。
- 优化联系人卡片、工作台导航、模型选择和成果预览，以及窄窗口下的布局。
- 改进任务上下文召回与写作草稿恢复，强化后台运行时取消、退出清理、每日消费记录和主动消息持久化。
- 修复静止鼠标时弹窗及布局变化后的穿透状态，修复更新检查/下载失败和窗口关闭后的迟到回调。

## 安装与更新

- Windows：下载 `ChouYu-Setup-1.4.3.exe`。
- macOS：下载 universal DMG，支持 Intel 与 Apple Silicon；内置 DSH 运行时仅提供 Windows x64 版本。
- 已安装版本可通过「设置 → 关于 → 检查更新」升级。
- 升级前建议保留完整用户数据备份；联系人快照不替代完整备份。

## 已知限制

- 安装包未配置代码签名，macOS 未公证。
- 界面设计师需要支持图片输入的模型；在线模型生成质量仍需实际使用验证，长文检查为有限采样。
- 联系人后台任务仍需应用运行；多个联系人共用后台进程，进程重启期间工作会短暂中断。
- 干净系统安装/卸载/自启、公开自动更新端到端、实体睡眠/唤醒和混合 DPI 多屏尚未完成专项验收。
