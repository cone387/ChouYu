# ChouYu v1.4.10

联系人头像、通知卡片和成果阅读体验更新。

- 新增 14 款统一风格的内置插画头像；现有联系人自动采用新形象，新建和编辑时可以选择。移除旧 emoji 头像选项，保留联系人与会话历史。
- 提醒每个事项单独发送，启动积压及恢复时也各发一条；消息显示独立的未读／已读标识，与处理状态分开。
- 通知改为紧凑卡片，突出事项内容和主要操作；来源、间隔设置等收进更多菜单。
- 会话时间区分今天、昨天、月日和跨年日期；打开或自动保存旧会话不再把显示时间变成今天。
- 成果阅读支持按文章、章节、报告、想法与步骤进行展示；保留原文、来源和阅读位置，异常时回退原文。
- 更新阅读依赖与校验库，修复发布安全检查发现的高危依赖问题。

更新需要重启应用。阅读消息不会代替处理提醒；未处理事项仍按保存的间隔跟进。
