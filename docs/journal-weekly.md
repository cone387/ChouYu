# 周报草稿

2026-09-09 首版已接入「工作日志 → 周报草稿」。选择起始日期后覆盖连续七个本地日，默认本周一。来源采用与该范围相交的收藏事项；可按标题、备注和项目名称查找，每页 50 份，可选择本页已完成项或逐条勾选。生成前需确认选中事项，最多 100 份。不调用模型，不发送网络请求。

草稿分为已确认进展、已确认决定、未完成与下一步。决定分类会在选择界面提示核对；其余事项只有收藏当前手动标记完成才进入进展部分。下一步仍标记为建议。日期来自事项发生时间，完成标记没有独立时间戳，因此不宣称事项在本周完成，不把采样时长当精确工时。无选中内容的分类明确留空，不补写成果。

项目手动归属直接展示；规则匹配的建议及多项目歧义保持待确认措辞。生成使用来源摘要指纹，所选收藏内容、完成状态或项目归属变化后要求刷新来源重新确认。创建与编辑使用 SQLite IMMEDIATE 事务；数据库版本升至 10。

每次生成独立保存新草稿，不覆盖旧稿。可编辑标题与 Markdown 正文，再保存、预览和导出。最多保留 100 份周报；标题最多 120 字、正文最多 60000 字。生成内容超限时拒绝并提示减少来源，不静默截断。编辑和删除校验版本，编辑失败保留本地草稿；未保存或过时的编辑需要保存核对或明确放弃后才能切换编辑、生成新稿。导出只使用已保存版本，并在保存对话框前后复核版本；取消不写文件。

周报正文独立于收藏。来源删除后保留正文，在应用和导出文件中提示无法回看；来源仍存在时可回看其独立截图与 OCR。项目后续更名或删除不改写历史草稿。删除周报不会删除收藏。当前不自动更新草稿、不定时生成、不直接发布或发送周报。
