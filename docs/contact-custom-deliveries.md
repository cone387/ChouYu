# 联系人任务成果与界面设计师

更新：2026-11-06。任务产品约束以 [联系人任务规范](contact-task-spec.md) 为准。

## 使用方式

作者联系人负责正式正文、来源与文件。正式成果保存成功后，系统自动交给独立的「界面设计师」处理；普通聊天、接单计划和流式草稿不触发。ChouYu 安排的已保存执行结果也进入同一流程。历史成果在打开或产生新结果时惰性登记，不在升级时全库生成。

设计完成前可以立即阅读原文。共同成果区提供「成果界面」「原文」「调整界面」和独立界面版本记录。调整使用一个自然语言弹窗；正文改写仍交给作者。阅读中的界面不会被后台替换，新界面或新成果提供明确切换入口。正在阅读历史正文时，调整不能悄悄针对更新的正文。

正文随任务详情统一纵向滚动，不再嵌入独立限高阅读框。切换任务标签和继续阅读保留位置；成果集返回按钮保持可达。生成界面按内容自然展开，若仍制造内层纵向滚动或持续改变高度，系统回到原文并显示错误。设计代码不要使用视口高度单位或固定高度的纵向滚动正文容器。

设计师拥有独立人设、模型与工作设置，复用既有执行器、全局并发、调用和 Token 账本。暂停设计师不会暂停作者；恢复后继续最新有效目标。来源暂停不自动开始设计，用户明确请求可处理保存的成果；任务完成仍可以设计最终成果。删除来源会使引用失效并取消对应设计。

## 设计与发布

设计师得到真实目录、分段读取工具、实际阅读容器截图、版本化主题 token 和已有的新机制设计。它可编写 HTML/CSS/JavaScript，自行选择小说、研究、想法或评审的结构。正文由宿主绑定到 `data-result-section`，只读数据为 `window.resultSource`。读取范围留有记录。

先尝试将适用的已验证设计绑定新正文，重新预览和视觉检查；不适用或用户明确要求修改时再生成代码。每次最多三轮候选，总时限十分钟。375/1024 宽度、亮暗主题分别渲染，检查正文绑定、导航可达、溢出和实际控件操作，并将真实图片传给模型复核。发布时再次检查来源与请求版本。

Native 图片通路已接入。当前 DSH 后台声明不支持图片，会明确阻塞，保留原文和重试入口，不静默换执行器。供应商拒绝图片、额度不足或验证失败同样不能发布未验证页面。

## 安全与可靠性

预览使用独立、可终止的 Electron 窗口；正式阅读使用 `chouyu-result:` 和不带同源权限的 sandbox iframe。两者使用同一文档生成器。页面不能访问网络、文件、Node/Electron、宿主控件或其他联系人。脚本异常、预览超时或取消时释放资源；正式页面异常可返回原文。

正文版本和界面版本分别存储。调整界面不调用作者提交、不改变正文版本和任务状态。设计完成通知由设计师发送，保留实际来源链接，通过现有持久回执、去重和未读提醒送达，不重发作者全文。普通重启重放未送达通知；备份恢复不重发恢复前的旧通知。

删除旧作者展示机制：不读取、执行、导出或恢复旧 `presentation`，不保留旧修改工具、协议或转发别名，旧运行和待确认请求直接失效。作者正文、来源、文件和历史继续保留。导出保留 Markdown。引用、收藏和精确阅读位置沿用原文阅读器；界面内需要引用时切回原文重新选取。

## 验证

运行 `npm run typecheck`、`npm test`、`npm run check:boundaries`、`npm run build`，以及 `node scripts/smoke-electron.js --result-designer`。后者使用隔离数据和本地模型协议夹具，覆盖真实预览、图片传输、工作进程、发布、原文切换、调整弹窗和消息投递，不消耗在线模型额度。

测试记录和未覆盖范围见 [本轮验收记录](result-designer-acceptance-20261106.md)。模型看图通过不是对美观的客观保证，线上模型的创作质量仍需实际内容试用。
