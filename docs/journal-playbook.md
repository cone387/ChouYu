# 踩坑手册进度

2026-09-09 已完成数据层、日志 IPC、编辑界面和 Markdown 文件导出。支持来源选择/回看、项目筛选和正文搜索；已接入明确预览并确认后的长期记忆写入。普通手册保存仍只写本地日志；只有点击确认写入，才调用当前记忆引擎。

每条记录包含标题、问题、尝试过程、解决办法、待解决/已解决状态、可选项目及最多 10 份收藏引用。标题和问题必填，标记已解决必须填写解决办法；这是用户手动记录的状态，不是模型或程序证明问题已解决。允许没有来源的个人记录，导出时明确写出未关联来源。

最多保留 200 条手册，标题最多 120 字，问题/解决办法分别最多 4000 字，尝试过程最多 8000 字。只引用收藏 ID，不复制图片或 OCR。删除来源收藏后保留用户写下的手册正文，并标记来源已删除、无法回看；不得为新手册关联不存在的收藏。旧手册仍可编辑正文并保留已失效的原引用。

删除项目保留手册正文、清除项目关联并递增版本；删除手册不删除项目或收藏。编辑和删除必须提交当前版本号，过时编辑或对已删除记录的操作失败，不恢复旧记录。写入使用 IMMEDIATE 事务。日志数据库升级至版本 9。

Markdown 格式包含用户手动状态、问题、尝试、解决办法及来源可用性，不把没有填写解决办法的事项描述为已完成。来源采用应用内收藏 ID，不伪造外部链接。

验证：439 项单测、类型检查、生产构建及完整 Electron 回归通过（`temp/journal-playbook-memory-smoke.log`）。单测覆盖字段限制、状态和来源校验、导出措辞；真实 SQLite 验证重开后持久化、过时编辑/删除拒绝、来源缺失、项目删除后的版本失效及独立删除。界面回归覆盖编辑保存、来源截图、筛选搜索、Markdown 预览、导出/取消、导出对话框期间版本变更拒绝覆盖文件，以及删除手册保留来源。已查看 1024 宽浅色与 560 宽深色截图。截图采集使用合成来源，不代表原生窗口采集验收。

界面每页显示 20 条手册；来源选择每页 50 份，可按标题检索，已选来源独立显示。编辑失败保留草稿，过时版本需要刷新后重新核对。导出通过系统保存对话框选择 Markdown 文件，打开对话框前及确认保存后均检查版本；取消不会写文件。

长期记忆入口仅对已手动标记解决的手册开放。用户整理 1–500 字摘要后预览，不静默截断长正文；可标记敏感。确认页展示本机或 Mem0 地址及用户范围、Embedding 地址（含主模型地址回退）和待处理规则。写入类型为工作流程，附手册标识，不上传截图、OCR 或完整手册。

服务端预览限 10 分钟、绑定窗口且单次使用；准备不调用记忆写入，确认前重新验证手册版本、状态及配置。关闭确认界面不会写入；已发出的写入请求需等待结果。记忆冲突返回待处理状态，失败保留摘要并提示核对记忆库，不自动重试；重复提交已有冲突候选不会绕过审核。相同内容可复用已有记忆，来源字段可能仍指向原记录。写入后记忆与手册独立，后续编辑或删除手册不会同步修改或删除记忆。

新增单测覆盖失效/跨窗口确认、配置变更、删除和未解决记录、长度/秘密检测、地址展示、失败及待处理结果。真实 SQLite 与界面回归覆盖预览和取消不写入、确认后的摘要和手册来源持久化、冲突候选重复提交保留审核及待处理反馈。Mem0 使用既有确认写入接口；尚未使用真实云端账户验证此入口。周报草稿已接入，详见 [周报说明](journal-weekly.md)。

回归过程中发现聊天离线 OCR 尚在运行时，通用 5 秒界面等待会提前失败。仅该 OCR 断言改为 35 秒（原生 OCR 自身超时为 30 秒，另留界面回传时间）；其他界面等待仍保持 5 秒，识别结果、草稿保留和无网络请求断言不变。
