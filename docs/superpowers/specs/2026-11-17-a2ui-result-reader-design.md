# A2UI 成果阅读试用版

用户在 A2UI 源码评估后要求在成果展示中引入一版试用。范围是已有正式成果的可选展示，不修改执行引擎、正文生成、通知或任务 UI。

## 方案

采用官方 `@a2ui/react`、`@a2ui/web_core` 0.15.0 和协议 1.0，以宿主生成的组件描述先验证真实渲染。与全面改写设计师相比，保留现有 HTML 展示可直接比较；与手写仿制协议相比，真实 SDK 能暴露集成问题。首版固定阅读组合不是模型自主布局，后者仍是后续能力，不能声称已完成。

成果工具栏增加「分节阅读」，仅有正式来源时可用，默认仍保持当前展示。「原文」和已有「成果界面」可随时切换。分节阅读有标题、可折叠目录、完整分节正文及已保存来源；目录按钮只在当前阅读容器内定位。使用已有主题和 ContactMarkdown，不引入新的业务动作或表单。

组件目录只包含宿主阅读组件。描述中只存分节索引，正文从本次固定来源快照读取，不接受 UI 事件改写正文。来源更新不自动切换当前成果；强制原文、错误与无来源时走原文。依赖通过 npm 精确版本安装，不依赖旁边的源码目录。

## 验收

单元验证分节顺序、重复标题、完整长文、来源隔离和空来源拒绝。真实 Electron 检查 A2UI 加载、目录跳转、原文/设计切换、375/1024 深浅色、无横向溢出；保留现有设计师验收。构建、类型及模块边界通过。模型自主 A2UI 组合、性能收益和在线模型效果不纳入首版已验证范围。
