# A2UI 成果展示继续迭代

用户反馈打开联系人看不到变化，要求继续迭代。既有产品规范要求成果按任务特点动态呈现，独立设计师负责展示，正文和来源不可重写。本轮是已授权试用的延续。以下技术取舍由实现者决定，不声称用户逐项确认。

## 体验与范围

成果集仍是进入作品的入口；打开作品或任务成果即使用适配阅读，不再隐藏在「分节阅读」按钮后。旧版正式成果同样可读；无成果不伪造示例。原文和已验证的设计界面都可切换。来源版本保持固定，后台变化只提示。

阅读按内容选择文章、报告、想法或步骤布局。长文留足正文空间，结论/建议在其原有分节突出，多个想法可并列；窄屏归为单列。目录以真实标题定位，不编造摘要、统计、图表或完成情况。所有正文完整保留，Markdown 表格、代码和来源正常可读。

## 方案取舍

只调整按钮不能满足用户的可见效果；全面替换旧设计历史会损坏已保存成果的展示。本轮采用默认适配阅读 + 设计师受约束的组件组合：即时阅读无需模型，设计师可以根据内容和用户要求选择布局并保存，复用既有预算、版本、失败处理及视觉验收。模型只生成布局和分节引用，不生成替代正文。保留原 HTML 设计历史。

## 验收与完成边界

1. 两个真实入口默认可见，原文/设计切换后不会被轮询覆盖。
2. 多种内容实际不同排版，375/1024 深浅色无横向溢出，完整长文可达。
3. 组件协议拒绝未知节点、缺失/重复分节与跨来源引用；错误回退原文。
4. 设计师生成、保存、复用、调整 A2UI 组合，预览使用实际渲染组件；已有 HTML 历史可读。
5. 固定版本、引用来源、返回与继续阅读保持现有契约。
6. 类型、构建、受影响测试、隔离 Electron 实际交互和截图验证。夹具验收不冒充在线模型审美质量。

全部验收前目标保持 active；完成即时阅读不等于完成模型设计链路。

## 可组合页面阶段

现有已保存布局仍可用。在分节布局上增加可选 groups：每组以 stack、columns、tabs 或 disclosure 展示一组真实分节。全体分节仍必须仅出现一次；组名仅用于导航标签，不作为正文、结论或来源。限制60组，tabs每组最多12节，columns最多3节，避免无界容器和不可操作的标签栏。

这是实现者在用户尚未回复展示偏好问题时按已说明方向作出的设计选择，不是用户确认了具体组件格式。既有五类布局不认定为最终目标。

目录与初始分节链接会展开并切换到真实目标，再定位正文；键盘支持标签切换。折叠和切换只影响可见性，完整保存正文仍由同一组件渲染。窄屏并列归为单列；表单、任务引擎、正文与消息规则不变。实际预览需通过操作走到每个隐藏分节，不能只检查它存在于DOM中。
