# Agent 通用自主工作能力：方向更正

日期：2026-10-27。状态：用户纠正后的能力方向与初步代码核对，不是新的模式设计；功能尚未改动。

后续已完成 Native/DSH 隔离链路核对与 54 项相关回归，具体缺口、正向对照和未验证事项见 [通用能力核对记录](../../agent-autonomy-audit-20261027.md)。

产品规则沿用 [联系人任务规范](../../contact-task-spec.md)。原 [持续探索模式草案](2026-10-27-continuous-exploration-design.md) 已撤回。

## 用户明确的方向

自主找方向、查资料、判断价值、记住尝试和继续推进，是 agent 本身应有的能力。用户给目标，agent 根据目标决定怎么做；不需要另选“探索模式”，也不因任务内容不同而开发一套专用执行流程。

“持续找有希望赚钱的点子，技术与非技术都可以”是首个任务示例。赚钱路径、客户、收费、验证方式等应由 agent 根据任务组织为成果，而不是写成程序必填业务字段。持续性由用户任务要求及现有运行设置决定，不等于给所有任务无限续跑。

## 能力增强应体现在哪里

1. **自主推进**：结合目标、已完成工作和阻碍选择下一步；可提出方向、调用已授权工具、核查、修改方案或适时提问，不由程序规定每项任务都经过同一套业务步骤。
2. **跨轮接续**：能回看相关成果、尝试和理由，分清真实完成、待核查和未尝试，不依赖模型记住上一次聊天。
3. **反馈生效**：用户接受、否定或修改要求后，后续工作能检索到相关意见及其对象；不把 task 范围的意见扩大为联系人永久偏好。
4. **判断与纠偏**：用实际结果检查是否推进了目标；发现重复、证据不足或思路无效时能换方法或补查。模型自评分不代替真实依据。
5. **持续交付**：按任务需要保存并交付想法、文章、评审或其他成果；有可推进内容继续，无变化、确实受阻、用户暂停或目标结束时如实处理。

上述描述是用户可观察的行为，不预先对应五个新增模块。先用现有能力验证并定位具体缺口，再决定需要改哪些共享契约、工具或上下文。

## 下一步应验证的能力场景

- 开放任务：给出“持续寻找赚钱点子”，不额外要求模式、行业或商业模板，观察是否自行选题、合理查证并推进。
- 历史接续：把某个关键尝试、反证和用户否定放在较早轮次，验证后续能检索、引用并据此调整，跨重启仍有效。
- 自主纠偏：资料与先前猜测冲突时，验证 agent 修改判断，而不是重复原结论或假称完成。
- 泛化：换成研究课题、写作和评审目标，使用相同能力入口；成果结构随任务变化，不强制客户/收费等商业内容。
- 运行边界：持续任务不因完成一条成果而结束；有限任务不自动变成无限任务；暂停、删除、权限和现有工作设置继续生效。

确定性回归核查持久化、归属、版本、工具实际可达性和调度；模型场景评估核查是否会使用这些能力。两者分开记录。上述为下一步诊断范围，不表示已运行在线模型或已开始真实赚钱研究。
