# 全 App 图表看板迭代

用户纠正：看板属于整个 App，应更多采用图表。此前「直接做」授权继续有效，本轮直接在现有看板上迭代。

## 设计

保留现有全局导航和深浅主题，使用应用原有字体。布局以活动趋势大图为主，右侧待办完成分布；下方依次展示应用时间分布、记忆分类、会话分布；联系人消耗和原全员活动降为独立分区。移除占据主区域的联系人卡片列表。联系人筛选只作用于联系人分区，不冒充全 App 过滤器。

配色沿用背景/文字语义 token；图表使用蓝 #4279c8、青 #258b83、紫 #8270b5、金 #b28435，暗色提高亮度。24/18/14px 信息层级，左对齐；无装饰动画、无外部字体与新依赖。图表有准确单位、文本数值、键盘可达和数据表。空值不造趋势，无数据零值与加载失败分开。

```
全局看板                         近7天 / 近30天
活动时间 | 待办 | 未读消息 | 记忆
活动时长趋势（大图）              用户待办（环图+每日完成柱图）
应用使用时间          记忆分类           会话消息分布
联系人累计消耗 / 独立筛选          实时活动
```

日期范围只控制明确标为本期的活动趋势、应用时长和每日完成量；当前待办、记忆、会话累计和联系人累计明确各自口径。普通聊天用已有会话摘要统计，不加载完整正文或宣称覆盖全 App Token。助手安排保留原任务界面，不增加一套编辑器。
