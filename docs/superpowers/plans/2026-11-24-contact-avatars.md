# 联系人内置头像实施计划

依据：用户已确认 8 人插画效果图，并要求设计、更新现有 agent 头像。

后续约定（覆盖下述首版的自定义头像保留规则）：用户要求「旧的可以去掉了」。已删除 emoji 快选及文字头像输入，所有已有身份统一显示插画；预设身份使用对应插画，自定义身份用稳定 ID 选定人物插画。显式选择优先，保存写入预览对应 token，不更改姓名或历史消息。旧数据库字段兼容读取；图片失败用姓名文字兜底，移除 emoji 兜底。

设计：14 张独立低饱和插画（丑鱼、设计师及 12 个预设联系人），沿用确认图的角色形象，补齐其余角色。通过公共 CharacterAvatar 渲染；旧默认 emoji 按身份映射到图片，不改写联系人存储。用户自定义 emoji/文字保留。新建/编辑复用现有头像区域，增加内置图片选择，保存短标识并兼容现有 8 字符限制。旧助手的默认形象归为丑鱼。

选择本地图片而非重新绘制 SVG，以保留用户确认的插画；本地资源随应用构建，不依赖网络。原图留在 temp/avatar-design，应用使用缩小后的 PNG。

- [x] 测试旧身份默认映射、自定义保留、内置选择和存储兼容。
- [x] 接入公共头像组件及编辑选择区，图片失败回退。
- [x] 检查深浅主题、小尺寸及选择保存；运行相关测试、类型检查和构建。

边界：不改变身份、人设、任务或消息内容；不自动提交、发布或替换正在运行的安装包。
