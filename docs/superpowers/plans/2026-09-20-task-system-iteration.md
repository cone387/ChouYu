## 入口与规则

- 截止范围：任务工具栏「筛选」弹层底部，位于清单筛选之后。“今天截止”只匹配截止日期；侧栏今天／明天／本周匹配执行区间。
- 回收站、备份恢复：任务内容标题旁「…」。备份覆盖任务工作区，恢复前自动生成安全备份。只接受相同任务数据库版本的备份，当前为 v9。
- 快速新建：「新建任务」右侧下拉，或任务页 Ctrl / ⌘ + N。输入框中不拦截该快捷键。
- 批量：仅操作当前已加载且明确选择的任务；改变筛选或视图清空选择。每批最多 1000 项，事务整体成功或回滚。
- 子项：最多 100 项，不独立提醒，不自动改变父任务完成状态；重复任务下一期重置勾选。
- 来源：任务备份保留来源引用和任务内容，不复制整份聊天／日志数据库；来源缺失显示明确反馈。
- 聊天工具 `create_task` 在所有权限模式下均要求确认。来源使用实际发起请求的会话，模型不能指定其他来源。
