# Windows 安装性能修复

用户要求直接实施安装优化。基线：正式 1.4.4 在本机 C 盘临时目录到 D 盘安装约八分钟；运行时 27,807 个文件、600,817,723 字节。

1. 发布复制时排除编译类型声明与 JS/TS source maps，保留开发依赖原件、运行 TypeScript、任意资源、许可证和所有功能依赖。
2. 通过真实复制夹具先复现冗余文件，再验证裁剪后模块执行与资源读取。发布与普通 CI 都运行此检查。
3. 重新构建完整 Windows 成品，运行依赖清单检查、DSH 成品冒烟及项目测试。
4. 用独立应用标识、独立安装目录的完整负载测量首次安装与升级，不修改用户当前运行的 ChouYu 或数据。
5. 记录实测结果和限制，交付普通 EXE。

安装器暂存搬运改造需保留增量更新及失败处理。现有 ZIP 直解压分支要求关闭 differentialPackage，且与 7z 分支的失败处理不同；不为了省一次复制直接替换。先以本次散文件裁剪实测决定后续是否需要更换安装机制。
