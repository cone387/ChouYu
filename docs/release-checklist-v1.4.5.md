本次只改变 Windows x64 DSH 发布依赖的复制规则，减少编译声明、源码映射和其他平台的 node-pty 二进制，保留目标平台运行组件。沿用 1.4.4 的长路径升级修复，不改变任务或聊天逻辑。

## 本地验证

- 最终运行时：27,807 → 14,807 个文件；600,817,723 → 508,557,267 字节。
- 复制夹具红灯复现后通过，真实模块执行、资源及许可证保留、开发依赖不变均验证。
- 类型检查和模块边界通过；全量 317 文件、2,385 项通过，17 文件、62 项跳过。
- 成品运行时清单与 Node 校验通过；最终 14,797 个保留依赖文件与开发依赖逐字节一致。
- 完整 DSH 和完整桌面成品冒烟复测通过。首次 DSH ready 超时与首次桌面鼠标穿透状态超时均保留，不宣称这些间歇性问题已根治；详见 [安装性能记录](windows-install-performance.md)。
- 独立代码审查无阻塞项；基准程序补充了输入依赖锁与保留文件内容比对，防止混合不同依赖版本。

## 发布门槛

`v1.4.5` 使用既有标签发布流水线，要求质量、两平台构建、SQLite、Windows 安装器长路径/旧版升级、完整桌面、DSH、历史数据升级和联系人恢复通过后才公开。

新增 `test-packaged-installer.cjs`，仅在 GitHub Windows 临时构建机上安装真实发布 EXE。先拒绝已有 ChouYu 安装或数据，再完整核对安装目录清单、Node、SDK 导入、数据保留和卸载，不以打包前目录的校验替代安装结果。

本地对比安装器使用相同的压缩等级 1；正式流水线使用仓库默认压缩配置。基准用于比较文件裁剪策略，不代表所有机器或正式默认压缩包都具有相同的秒数。
