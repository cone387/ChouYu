# DSH 后台接入验收（2026-10-19）

范围：完整 AgentSpace 计划的 Task 3。仍在 `feat/agentspace-complete` 分支；此记录不代表整个模块化目标完成。

## 实现

- 联系人编辑分别保存聊天与后台执行引擎，支持配置工具自然语言修改与版本校验。后台设置下一轮生效，执行快照固定当前选择；不改变助手提醒和晨报引擎。
- worker 注册实际 DSH 后台模块，执行真实 SDK；不回退原生。进程池由后台模块持有，模块关闭取消在途请求并等待退出。
- SDK 请求前预留精确序列化输入的额度；较低输出上限经过 SDK 正式配置与请求头日志后才发送。协商重试不发 HTTP，不增加调用记账。
- 多轮工具请求分别预留和结算，结算先于工具执行。工具循环最多六次模型请求；超时、取消、额度不足、供应商错误和输出截断传回原工作策略。
- SDK 缓存与普通输入分项合并；缺失和 SDK 合成全零用量作为未知，沿用原保守预算。
