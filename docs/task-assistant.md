# AI 任务助手

聊天中可查询真实任务、读取详情，以及确认后修改或完成一个任务。需配置支持工具调用的模型，并开启「AI 自动工具调用」及对应工具。

## 使用示例

- “今天有哪些未完成任务？”
- “查一下工作清单里本周安排的任务。”
- “找一下标题或备注包含周报的任务。”
- “看看这项任务的备注、子项和提醒。”
- “把刚才选定的这项任务截止时间改到明天下午三点。”
- “这项任务做完了，标记完成。”

查询支持未完成、已完成、全部，以及今天、明天、本周、下周、逾期和指定清单。未完成任务按执行区间，已完成按完成日期；逾期沿用任务界面的本地今天零点规则。归档清单不进入查询。每页 20 条，返回总数和下一页偏移；任务详情的子项也按 20 条分页。工具卡片可直接打开任务，并显示清单、截止时间和短 ID 区分同名任务。

## 修改与确认

可修改名称、说明、优先级、开始时间、截止时间和任务提醒。未指定字段保留，空字符串可清除说明或时间。设置单次提醒会替换已有任务提醒，确认预览展示实际前后变化。子项和重复规则可读取，复杂配置继续使用任务编辑表单。

写操作先读取任务详情，携带内容版本，预览展示真实名称、清单、ID、字段变化，以及提醒平移、取消重复、完成后可能生成下一期等影响。即使在「完全访问」模式下仍须确认。拒绝、超时或取消不执行；确认期间任务或所属清单发生变化则拒绝旧操作，需重新读取后再次确认。

同名候选由模型先询问用户选择，最终预览使用精确 ID，数据库不会按标题匹配写入。一次对话请求最多允许一个任务写操作（含已有的创建工具），拒绝后也不会在同次回答中再次请求。没有增加快速新建、多选或批量操作。

- 单元测试覆盖真实 SQLite 查询分页、日历范围、已完成历史、归档、同名任务、版本变化、提醒联动和重复任务完成。
- `node scripts/smoke-electron.js --task-assistant` 使用隔离用户目录和本地模拟模型，验证真实 IPC、查询来源入口、确认界面、拒绝/取消、过期版本、单任务限制及重复任务完成。
- 模拟模型验证应用链路，不代表不同真实模型都能稳定理解同名消歧和自然语言日期。最终以确认预览为准。
